"我用一棵决策树:第一问合规(数据能不能出境/是否要私有化)——不能出境直接锁死国产(Qwen/DeepSeek/GLM);第二问任务类型——复杂推理/长文档/代码各有强项;第三问成本结构——API 按量还是自建 GPU 固定。然后分级使用:旗舰模型只打 10~20% 的硬仗,70% 流量给中档,简单活给小模型。选型结论永远附一个退出机制:通过统一网关接入,随时可换,不被任何一家锁定。"

通俗类比

像公司用车队:不能全买迈巴赫(旗舰模型,贵但强);也不能全买三蹦子(小模型,便宜但上不了高速)。合理车队是:高管商务接待(复杂推理)用迈巴赫,日常公务用帕萨特(中档),园区通勤用电瓶车(小模型)——分级派车才是成本和质量的平衡。而且车都从"租车平台"(统一网关)租,哪家服务好随时换,不跟单一车行签死。

3. 分级路由架构(把选型变成系统设计)

  • 意图/难度分类器(或先小后大的 cascade 策略:小模型先答,置信度低再升级)。
  • 通过统一网关路由(见第一部分 Q6),模型只是一层可替换的配置。
  • 每档模型配质量护栏:小模型答案过校验(引用存在性/格式),不过关自动升级重答。

4. 微调 vs 直接用(自然延伸)

  • Prompt 解决不了的:格式死活不稳、领域黑话不懂、工具选择太差 → 先试 Few-shot,再微调小模型,别上来就微调旗舰。
面试官追问
Q:国产模型和 GPT-4 差距还大吗?
头部国产旗舰在中文场景、常见 Agent 任务上已可比肩甚至局部反超;差距主要在最前沿推理、生态工具链和极端长上下文稳定性。我的策略是按任务实测,而不是信仰品牌。
Q:怎么防止被单一供应商锁定?
统一 API 抽象(适配器)+ 数据可迁移(Prompt/评估集都是资产,和模型解耦)+ 每季度平行测试备选模型——换模型的工程成本应保持在"改配置"级别。
术语卡
Cascade 策略:先小后大逐级升级。
私有化部署:模型跑在自己机房。
供应商锁定:被单一厂商绑死,切换成本高。
