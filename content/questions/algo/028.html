推导 Temperature Scaling 对概率分布的影响

⭐⭐⭐ #Temperature#采样#理论
30秒电梯稿

"温度 T 是对 softmax 输入的缩放因子:pᵢ = exp(zᵢ/T) / Σⱼ exp(zⱼ/T)。三个关键结论:① T=1 是标准 softmax;② T→0 退化成 argmax(只留概率最大那一个);③ T→∞ 退化成均匀分布。数学上可以严格证明:熵 H 关于 T 单调不减,导数 dH/dT = Var(z)/T³ ≥ 0——温度越高,分布越平、熵越大、采样越"随机探索";温度越低,分布越尖、越确定。所以高温用于采样多样性和知识蒸馏,低温用于贪心解码和校准修正。"

通俗类比

把 logits 想象成几个候选人的"能力分",温度就是面试官的严格程度:温度很低时,面试官只把 Offer 给第一名,几乎不看别人(接近 argmax);温度适中,能力强的概率大、弱的概率小;温度很高时,面试官佛系了,大家机会几乎一样(均匀)。所谓"熵变大",就是结果从"基本确定"变成"谁都可能",这就是温度调节采样随机性的本质。

详细拆解

1. 定义

pᵢ(T) = exp(zᵢ/T) / Σⱼ exp(zⱼ/T)      # zᵢ 为第 i 类的 logit,T > 0 为温度
  • 温度不改变排序:zᵢ > zⱼ ⟺ zᵢ/T > zⱼ/T,所以 argmax 永远不变,T 只改变概率的"集中程度",不改冠军归属。

2. 两个极限(直接看定义即可证)

T → 0⁺ :  pᵢ → 1(若 zᵢ 最大),否则 → 0     # 退化为 one-hot / argmax,熵 → 0
T → ∞  :  zᵢ/T → 0, pᵢ → 1/K            # 退化为均匀分布,熵 → ln K(K 为类别数)
  • 严格说 T→0⁺ 要求最大值唯一;若最大值并列,则概率均分到这些并列项上。

3. 核心证明:熵随温度单调不减

定义配分函数 Z = Σⱼ exp(zⱼ/T),期望 ⟨z⟩ = Σᵢ pᵢ zᵢ。由 pᵢ = exp(zᵢ/T)/Z 可得:

H = −Σᵢ pᵢ ln pᵢ = ln Z − (1/T)⟨z⟩

对 T 求导,分两步:

dZ/dT = Σⱼ exp(zⱼ/T)·(−zⱼ/T²) = −(1/T²)Σⱼ zⱼ exp(zⱼ/T)
d(ln Z)/dT = (1/Z)(dZ/dT) = −(1/T²)⟨z⟩

再算 ⟨z⟩ 对 T 的导数。由 d(ln pᵢ)/dT = −zᵢ/T² + ⟨z⟩/T² = (⟨z⟩ − zᵢ)/T²,得 dpᵢ/dT = pᵢ(⟨z⟩ − zᵢ)/T²,于是:

d⟨z⟩/dT = Σᵢ zᵢ (dpᵢ/dT) = (1/T²)[⟨z⟩² − ⟨z²⟩] = −(1/T²)Var(z)

合并两段:

dH/dT = d(ln Z)/dT − d[(1/T)⟨z⟩]/dT
      = −(1/T²)⟨z⟩ − [ −(1/T²)⟨z⟩ + (1/T)(d⟨z⟩/dT) ]
      = −(1/T)(d⟨z⟩/dT) = Var(z)/T³ ≥ 0
  • 因为方差 Var(z) ≥ 0、T³ > 0,所以 dH/dT ≥ 0 恒成立——温度升高,熵只增不减,分布单调变"平"。
  • 这严格证明了"T 越大越均匀、越随机"不是经验感觉,而是数学结论。

4. 与自由能/优化的联系(进阶理解)

  • 可把带温度 softmax 看作带熵正则的优化解:p(T) 是"在给定能量 z 下最大化 H、且 −log Z 是对应自由能"的分布族。T 即温度,对应正则强度。
  • T→0 即去掉熵正则,回到硬最大;T→∞ 即只最大化熵,回到均匀。

5. 三个实战用途

用途方向原因
采样多样性T ↑分布更平,缓解重复与退化,生成更有创造性(对话、写作)
知识蒸馏T ↑(教师)软标签保留类别间相对关系,给学生更多"暗知识"(Hinton 2015)
校准(Calibration)T ↑(通常)过自信模型调大 T 使概率更贴合真实频率,降低 ECE(Guo 2017)

6. 与 top-p/top-k 的关系:温度改变整个分布的锐度,top-k/top-p 则是"截断 + 重归一化",两者正交,常组合使用(如 temperature=0.7 + top_p=0.9)。

面试官追问
Q:温度会把 argmax 变掉吗?
不会。T > 0 时 exp 是单调增函数,除以 T 只是单调缩放,zᵢ/T 的相对大小不变,argmax 恒等。温度只重分配概率质量,不重排顺序——所以"调温度"改变的是随机性,不是"该选哪个最好"。
Q:知识蒸馏里为什么老师用高温、学生推理时又用 T=1?
训练时对老师 logits 除以高温再 softmax,得到平滑的"软标签",它能透露"猫更像狗还是更像卡车"这类类间相似结构,信息量远大于 one-hot;学生训练完、推理时恢复 T=1,得到正常的校准概率。若学生也用同样高温推理,概率会被过度抹平、置信度失真。
Q:校准为什么通常要把 T 调大于 1?
现代大模型普遍"过自信"——softmax 输出的概率(如 0.98)高于真实正确率(如 0.85)。调大 T 使分布变平、峰值下降,让预测概率逼近经验频率,从而降低 ECE。T 本身是在验证集上最小化 NLL 学出来的单标量,不改变任何预测结果,纯属后处理。
术语卡
Temperature:softmax 的缩放因子,控制分布锐度。
熵 H:分布不确定性的度量,−Σp ln p。
argmax:T→0 的极限,只取概率最大的类别。
ECE:期望校准误差,预测概率与真实频率之差。
软标签:蒸馏中教师输出的平滑概率向量。
