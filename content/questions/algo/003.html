Agent核心 · Q15

训练 LoRA 模型时，你是如何选择冻结层的？依据是什么？

⭐⭐⭐ #LoRA#层选择 字节(真题)
30秒电梯稿

"结论:冻结全部预训练权重(基座),只在注意力层的投影上挂低秩适配器。默认做法是在 Q/K/V/O 四个投影层各挂一个 LoRA(工程上也有只挂 Q/V 或 Q/K/V 以省参数的做法);Embedding 和 LayerNorm 通常也冻结。依据三条:① 参数效率——冻结基座让可训练参数降到百万级,显存和算力下降几个数量级;② 效果——原论文表明只调注意力层就足以逼近全参微调;③ 防灾难性遗忘——基座不动,通用能力不丢。任务更难、数据更多时,再扩展到 MLP 层或调大 rank。"

通俗类比

像给一台高配电脑外接一个 U 盘:电脑本体(基座权重)原封不动锁死,你在 U 盘(低秩适配器)上装补丁,插上电脑就"升级"了。为什么只动 U 盘?因为拆主板重焊成本极高(全参微调要存梯度、优化器状态,显存爆表),而且乱动主板容易把原厂能力搞没(灾难性遗忘)。注意力层相当于"最值得插 U 盘的那个 USB 口"——对语义影响最敏感、收益最大。

详细拆解

1. LoRA 的数学原理(先讲清楚在冻结什么)

把权重更新分解成两个低秩矩阵的乘积,只训练这两个小矩阵:

h = W₀·x + ΔW·x = W₀·x + (B·A)·x
# W₀: 冻结的原始权重  d×k
# A ∈ R^(r×k): 降维矩阵, 高斯初始化
# B ∈ R^(d×r): 升维矩阵, 零初始化
# r << min(d,k): 秩, 常取 8/16/32
# 缩放因子 α/r; B 初始为 0, 保证训练开始时 ΔW=0

冻结的正是 W₀:不参与反向传播、不存梯度与优化器状态;可训练参数只剩 A、B。

2. 冻结什么、训练什么(层级清单)

模块默认处理原因
注意力 Q/K/V/O挂 LoRA(核心)语义表征最敏感,收益最大
FFN / MLP 层通常冻结存储"知识",动它易忘且参数更多
Embedding冻结(除非换词表)大且与任务无关,微调易过拟合
LayerNorm冻结或极小 lr 训练参数量小但影响分布,一般不动

3. 为什么"挂注意力、冻 MLP"(选择依据)

  • 效果依据:原始 LoRA 论文(Hu et al., 2021)在 GPT-3 上的实验表明,只对注意力层的 Q、V(甚至仅 Q/V 的一部分)加 LoRA 就能匹配全参微调;挂到全注意力层(Q/K/V/O)通常是最稳的默认起点。
  • 成本依据:注意力投影的参数量比 FFN 小一个量级,挂 LoRA 后可训练参数只占基座的万分之一到千分之一,显存、显存通信、检查点体积全面下降。
  • 遗忘依据:冻结基座从机制上杜绝了"学新任务把旧能力洗掉",这是做多任务/持续学习时的关键诉求。

4. 什么时候打破默认(重要 trade-off)

  • 下游任务与预训练分布差异大(如从通用语料微调到代码/医疗专域),可加挂 FFN 的 LoRA 或调大 rank,补足容量。
  • 数据少、任务简单:r=8~16 已够,挂 Q/V 甚至更省;数据多、任务难:r=32~64,并考虑 Q/K/V/O + FFN 全挂。
  • QLoRA:把基座量化到 4-bit 再冻结,LoRA 反向传播时反量化计算,进一步把显存压到单卡可微调大模型;这是资源受限时的首选。
  • 先冻结后解冻:也有"LoRA 预热 + 最后解冻 LayerNorm/部分层小幅精调"的做法,但工程上收益不稳定,默认不推荐。
面试官追问
Q:为什么不微调 Embedding 层?
三个原因:① 参数规模大(词表 × 维度,常占模型参数相当比例),微调它会显著增加优化器显存;② 它学的是通用 token 语义,对单个下游任务不是主要瓶颈,微调收益低且易过拟合;③ 冻结它有利于保持跨任务的一致性。例外是换词表场景(如新增大量领域专用 token),这时必须训练新 embedding 行,否则新 token 没有有效初始化。
Q:只挂注意力层什么时候不够?
当任务需要学到新的知识/事实而不仅是"换种说法"时——知识主要存储在 FFN 权重里,冻结 FFN 会让模型难以真正吸收新事实,只能靠注意力"拼凑"。所以:风格迁移、指令遵循这类"已有知识重排"的任务,只挂注意力就很好;而注入大量新领域知识、或任务分布偏离预训练很远时,要挂 FFN、调大 rank,甚至考虑全参微调。能区分"重排已有知识"和"学习新知识",是这道题的高分点。
Q:rank 怎么选?
经验值:小任务 r=8~16 足够,复杂任务 r=32~64。原则是从低到高试:rank 翻倍观察验证集,收益趋平就停。理论上 LoRA 的 ΔW 是低秩的,秩太小欠拟合、太大过拟合且逼近全参的成本。另外注意 α/r 缩放:调 rank 时要同步调 α(一般保持 α ≈ 2×r 的比例),否则会影响有效学习率。
术语卡
LoRA:冻结基座、只训低秩适配器的微调法。
低秩分解:用两个小矩阵的乘积近似大矩阵更新。
QLoRA:量化基座(4-bit)+ LoRA,极致省显存。
灾难性遗忘:学新任务导致旧能力退化。
rank:低秩矩阵的秩,控制适配器容量。
