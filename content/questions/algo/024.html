推导 Layer Normalization 的前向和反向传播

⭐⭐⭐⭐ #LayerNorm#前向传播#反向传播 无公司
先说人话:这题问的是 Transformer 里那个「把每个 token 的特征拉回同一尺度」的模块——它正向怎么算、反向梯度怎么传。面试官爱考它,是因为能同时验证你三条腿:链式法则的基本功、手推公式的耐心、以及是否真理解 LN 为什么在 LLM 时代赢了 BatchNorm。答错的暴露点很典型:只会背「减均值除方差」,一问「μ 和 σ 也是 x 的函数,梯度怎么绕回来」就卡壳——这暴露你没推过,只背过。
30秒电梯稿

"LayerNorm 对每个样本自身的特征维做归一化:先算均值 μ 和方差 σ²,再做 (x−μ)/√(σ²+ε),最后用可学习的 γ、β 做仿射变换。反向传播的关键结论是 ∂L/∂xᵢ = (dx̂ᵢ − mean(dx̂) − x̂ᵢ·mean(dx̂⊙x̂))/√(σ²+ε),其中 dx̂ᵢ = ∂L/∂yᵢ·γᵢ。相比 BatchNorm,它不受 batch size 影响、推理和训练行为一致,所以 Transformer 里全用 LayerNorm。"

通俗类比

LayerNorm(用备份系统的「单节点自监控」想):你做分布式备份,每个 agent 节点上报的指标量纲五花八门——CPU 是百分数、IO 是 MB/s、时延是毫秒。你不会拿「全公司平均 CPU」去归一化某一个节点的 IO(BatchNorm 的思路,跨样本),而是对这一个节点的这一批指标自己算个均值和波动,把每个指标换算成「偏离自身基线多少个标准差」——这就是 LayerNorm,沿特征维、逐样本操作。归一化完再乘 γ、加 β,相当于给每类指标配一个「告警门限系数」,让下游注意力层知道「这条线到底多大声算异常」。

哪里像:和备份系统里的「基线归一化」一样,目的都是把量纲不一的原始值拉到统一尺度,让下游(注意力 / 告警引擎)不用为每个维度单独调权重;ε 防除零就像监控代码里的 `max(σ, 1e-5)` 兜底。哪里不像:监控归一化是纯统计、只读不改数据;LN 带可学习的 γ、β(会反向更新),而且它是计算图里的算子,μ、σ 是梯度的必经之路,不能当常数——这正是手推反向的难点。

BatchNorm(用「跨机房横向对比」想):BatchNorm 是拿同一个特征跨样本算统计量,好比拿「所有节点的平均 CPU」当基线。问题:机房里只有 1 个节点(batch=1)时基线不存在;训练时拿实时均值、推理时用存下来的移动平均,行为不一致——就像训练和演练用两套剧本,容灾大忌。LN 逐节点自算,天然没这两个坑。哪里像:都是「减均值除标准差 + 仿射」的配方;哪里不像:统计量的「取样方向」差了 90 度(样本间 vs 特征间),这一个转置决定了 Transformer 只能用 LN。

详细拆解

1. 前向传播(是什么)

先把维度钉死:输入 x 是一个 token 的特征向量,长度为 d(比如 7680 维的 hidden state)。LN 不看别的 token、不看 batch 里的其他样本,只在这一个向量内部做三步:算均值 → 算方差 → 标准化 → 仿射。整个过程就是一个纯函数,同样的输入永远得到同样的输出——这是后面说「训练推理一致」的根。

# 输入 x ∈ R^d,沿单个 token 的特征维 d 做归一化
μ  = (1/d)·Σᵢ xᵢ
σ² = (1/d)·Σᵢ (xᵢ − μ)²
x̂ᵢ = (xᵢ − μ) / √(σ² + ε)      # ε 防除零, 如 1e-5
yᵢ = γᵢ·x̂ᵢ + βᵢ                # γ, β 为可学习的仿射参数
  • ε(如 1e-5):数值兜底,防止某个 token 的特征全相同(σ²≈0)时除零。跟存储系统里写盘前 `assert size > 0` 是同一类防御性编程。
  • γ、β:可学习的逐维缩放和偏移。为什么必须有?因为强制把每个 token 压成「零均值、单位方差」会抹掉表示中真实有用的分布差异,γ、β 把「该保留多大差异」的决定权还给模型。
前向数据流(一个 token 的视角):

      x (d 维原始特征)
      │
      ├────────────┐
      ▼            ▼
    求均值 μ      求方差 σ²   ← 两者都由 x 算出,梯度要绕回来!
      │            │
      └────┬───────┘
           ▼
   x̂ = (x − μ)/√(σ²+ε)        ← 标准化,零均值单位方差
           ▼
   y = γ ⊙ x̂ + β             ← 仿射,恢复表达能力
           ▼
      送入下一层(注意力/FFN)

2. 反向传播(推导结论)

设上游回传的梯度是 dy = ∂L/∂y。反向要回答四个问题:γ、β 各拿多少梯度?中间量 x̂ 拿多少?最终回传给 x 的梯度是多少?前三个是简单乘加,最后一个才需要动脑——因为 x 出现在三个地方(分子、μ 里、σ² 里)。

# 令 dyᵢ = ∂L/∂yᵢ(上游梯度)
∂L/∂γᵢ = dyᵢ · x̂ᵢ
∂L/∂βᵢ = dyᵢ

dx̂ᵢ = dyᵢ · γᵢ

# 对输入 x 的梯度(含均值/方差两条回传路径)
∂L/∂xᵢ = [ dx̂ᵢ − mean(dx̂) − x̂ᵢ · mean(dx̂ ⊙ x̂) ] / √(σ² + ε)

# 其中 mean(·) = (1/d)·Σᵢ(·), ⊙ 为逐元素相乘

逐项读这个公式:第一项 dx̂ᵢ/√(σ²+ε) 是「x 直接出现在分子里」的直通路径;第二项 −mean(dx̂)/√(σ²+ε) 是「x 又藏在 μ 里」的修正;第三项 −x̂ᵢ·mean(dx̂⊙x̂)/√(σ²+ε) 是「x 还藏在 σ² 里」的修正。注意这两个 mean 都是对整个特征维求的——每一维收到的梯度都掺着所有其他维的 dx̂,这就是 LN 反向不能逐元素独立算的原因,也是手推时最容易漏的地方。

3. 为什么这个反向公式是对的

  • 归一化 y = γ·(x−μ)/σ̂ + β 对 x 是线性的,但 μ、σ̂ 本身由 x 决定,链式法则要同时考虑三条路径:① 直接经 (x−μ)/σ̂;② 经 μ 的变化;③ 经 σ̂ 的变化。
  • 三部分合并后,等价于"先对 dx̂ 中心化,再减去与 x̂ 相关的投影",得到上面的紧凑形式。可用 Σᵢ ∂L/∂xᵢ·xᵢ 的守恒性质做数值验证。
  • 实操建议(面试加分项):写代码时用 torch.autograd.grad 对一个手工实现做梯度数值对拍,和有限差分比一遍——跟你验证一个备份恢复脚本「演练环境和生产环境结果一致」是同一个职业病,面试官听了会很亲切。两条对拍不变量:Σ ∂L/∂xᵢ 应等于直通项贡献的 0(中心化吃掉了均值分量);Σ x̂ᵢ·∂L/∂xᵢ 也应为 0(方差归一化吃掉了投影分量)。

4. LayerNorm vs BatchNorm

LayerNormBatchNorm
归一化维度特征维(每样本内)batch 维(每特征跨样本)
batch size 依赖无强
训练/推理一致性是需移动平均,行为不同
适用场景Transformer / RNNCNN

用容灾视角再读一遍这张表:BN 推理时用「训练期攒下来的统计量快照」,相当于容灾演练拿一份历史基线当现状——分布漂移(数据分布变化)时快照失效,行为悄悄不一致;LN 每次实时算,像每次演练都用当前生产数据做校验,一致性天然成立。这也是大模型训练里 batch size、序列长度、数据分布都在变的情况下,社区最终选 LN 的工程理由。

面试官追问
Q:为什么 Transformer 用 LayerNorm 不用 BatchNorm?
人话:三条路:序列长短不一、推理时没有 batch 可用、训练推理要绝对一致。类比:BN 像跨机房汇总基线——只要有一个机房节点数变动或只剩单节点,baseline 就抖;LN 像每节点自监控,单机也能算,演练(推理)和实战(训练)用同一套规则。技术:① 变长序列 + padding,让 BN 跨 batch 的统计量噪声很大;② 自回归生成逐 token 解码,batch=1 时 BN 统计量不存在;③ BN 推理依赖训练期保存的移动平均,行为不一致,LN 逐样本实时计算天然一致。所以 NLP/LLM 全线选 LN。
Q:反向公式里 mean(dx̂) 和 mean(dx̂⊙x̂) 是什么含义?
人话:它们是均值路径和方差路径「补票」的修正项,保证梯度传回去时不违反 LN 强加的两条纪律。类比:像分布式系统里的约束反演——你对 x 做改动(梯度更新),但系统约定输出必须保持零均值、单位方差,这两项就是把你的更新投影回合法子空间的纠偏项,防止梯度把归一化的效果「洗掉」。技术:x̂ 满足 Σx̂ᵢ=0 和 Σx̂ᵢ²=d 两个约束,对约束取梯度就得保证 Σ∂L/∂xᵢ=0、Σx̂ᵢ·∂L/∂xᵢ=0。mean(dx̂) 修正减均值路径,mean(dx̂⊙x̂) 修正方差路径,两项合起来正好满足两条守恒,可用数值对拍验证。
Q:Pre-LN 和 Post-LN 有什么区别?
人话:LN 放子层前还是后。放前面(Pre-LN)训练稳得多,现代大模型几乎全用它。类比:Post-LN 像备份任务在主干链路上「先跑完再校验」,每加一层,主干上多一个必过闸门,梯度从最后一层往回走时层层衰减,深了就断流;Pre-LN 像把校验挪到旁路,主干始终是干净的残差直通路(类似一条永不熔断的 fast path),梯度沿主干无损直达每一层。技术:Post-LN:x + LN(SubLayer(x)),对 warmup 敏感、深层易梯度爆炸;Pre-LN:x + SubLayer(LN(x)),恒等路径上没有非线性收缩,梯度更平稳,可省 warmup,代价是表示上限理论上略受限,但工程收益远大于此。
Q:RMSNorm 和 LayerNorm 有什么区别?
人话:RMSNorm 把「减均值」这步砍了,只保留「除以均方根 + 缩放」,更快,效果不掉。类比:像备份里的增量方案:全量备份(LN)固然完整,但实测发现「减均值」这份冗余数据对恢复质量没有贡献,砍掉后 I/O 减三分之一,SLA 更好——LLaMA 就是这么干的。技术:y = x/√(mean(x²)+ε)·γ。省掉均值计算和一次同步归约,GPU 上访存和同步都更少,参数也不需要 β;大量实验(含 LLaMA 系列)表明效果与 LN 持平甚至略好,所以推理侧新模型基本转向 RMSNorm。
Q:如果让我手写 LN 的反向,怎么自证写对了?
人话:两条验证:数值对拍 + 守恒校验,别只信自己的推导。类比:跟你验证恢复脚本一样——光 code review 不够,必须做一次真实演练(数值对拍),再查两个不变量指标(守恒校验),双绿才算过。技术:① 用 PyTorch 自动微分算出 ∂L/∂x 作为参考,和手写反向比对,容忍 1e-6 级误差;② 检查 Σ∂L/∂xᵢ≈0、Σx̂ᵢ·∂L/∂xᵢ≈0 两条守恒;③ 顺手测 batch=1 和含极端值(全同特征)的输入,确认 ε 兜底生效。面试里说得出「我怎么验证」比背出公式更加分。
术语卡
LayerNorm:沿特征维的逐样本归一化,Transformer 的标准配置。
BatchNorm:沿 batch 维跨样本算统计量的归一化,CNN 常用,NLP 里水土不服。
仿射变换(γ, β):归一化后恢复尺度和偏移的可学习参数,给模型保留分布差异的自主权。
RMSNorm:只保留均方根缩放的简化 LayerNorm,LLaMA 系列采用。
Pre-LN:LayerNorm 前置到子层输入,残差主干变成无阻梯度通路,训练更稳。
反向传播:沿计算图从损失往输入逐算子回传梯度的算法,链式法则的工程化。
ε(epsilon):归一化分母里的防除零常数(如 1e-5),数值稳定兜底。
