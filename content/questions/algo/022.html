推导 Softmax 的梯度

⭐⭐⭐ #Softmax#梯度#数学推导 无公司
先说人话:分类模型最后一层用 Softmax 把分数变成概率,这题要你推"某个输入动一点,每个输出怎么跟着动"的公式。面试官爱考它,一石二鸟:既验链式法则基本功,又看你看不看得穿"所有输出共享一个分母"的耦合结构。最大翻车点:把每个输出当独立函数求导,漏掉分母里的其他输入。
30秒电梯稿

"Softmax 把 logits 变成概率分布 y = softmax(z),这题要推它的梯度。结论很漂亮:∂yᵢ/∂zⱼ = yᵢ(δᵢⱼ − yⱼ)——对角元是 yᵢ(1−yᵢ)、非对角元是 −yᵢyⱼ。推导只需对商式求导,分 i=j 和 i≠j 两种情况,再用 Kronecker delta(δᵢⱼ)合并成一行。更实用的推论:Softmax + 交叉熵 合起来,梯度退化成 y − t(预测减真值),实现和推导都极简,这也是所有分类框架的标准写法。"

通俗类比

Softmax 像共享存储池里的份额分配表:K 个租户各报一个权重(logits),系统把他们换算成总带宽的百分比,所有份额加起来恒等于 100%——这就是"和为 1 的概率分布"。梯度问的是:第 j 个租户的权重上调一档,第 i 户的份额怎么变?答案很符合直觉:动的是自己(i=j),自己份额上涨,涨幅是 yᵢ(1−yᵢ);动的是别人(i≠j),池子总量恒定,他涨我必跌,所以是 −yᵢyⱼ。公式里的 δᵢⱼ 是个开关:下标相等取 1(打开"自己"那项),否则取 0。哪里像:总额恒定、零和博弈、一涨必有一跌,和存储 QoS 分配一模一样。哪里不像:真实 QoS 按权重线性切分,Softmax 在权重前先垫了一层 exp 放大镜——权重 2:1,分出来却是约 73%:27%,差距被指数级拉开。这个"放大差距"正是模型要的:让微小的分数差变成悬殊的概率差。

梯度矩阵像变更影响面分析表,链式法则像调用链排障:把所有偏导 ∂yᵢ/∂zⱼ 摆成 K×K 方阵(学名叫雅可比矩阵),第 (i,j) 格填"动配置 j,输出 i 抖多少"——和你做配置变更前画的影响面表是一回事。普通元件(比如逐元素激活)这张表是对角阵:各管各的,自己只影响自己;Softmax 因为共享一个分母,表里没有一格是空的——这就是"耦合"的矩阵证据。哪里像:都回答"谁动了、谁跟着动"。哪里不像:影响面表是定性的(受影响/不受影响),雅可比是定量的(精确抖多少),且数值连续可算。至于链式法则,本质是调用链排障:反向传播把损失从最上游一跳一跳往回传,每一跳乘一个局部偏导——和你沿 trace 逐跳看慢请求的耗时占比,是同一种思维。

详细拆解

1. 定义与性质(先把道具摆上台)

  • 设 z = (z₁,…,z_K),S = Σₖ exp(zₖ),则 yᵢ = exp(zᵢ)/S。z 的学名叫 logits——模型最后一层吐出的原始打分,可正可负、没有上下界;y 是归一化后的概率,一张加起来等于 1 的分配表。
  • 性质:Σ yᵢ = 1、非负、单调(zᵢ 增 → yᵢ 增)。注意每个 yᵢ 依赖所有 z 分量,这是"耦合"的来源——分母 S 把 K 个分数焊在一起,动任何一个 zⱼ,分母跟着变,所有 y 都要重新分账。这一条是整道题的灵魂:如果各管各的,它就是一道普通求导题;正因为共享分母,才有后面"非对角元不为 0"的雅可比矩阵,才值得面试官专门出一题。

2. 分情况推导(全场只用到一件工具:商式法则)

先复习商式法则:(u/v)′ = (u′v − uv′)/v²——分子分母各求各的导,交叉相减,除以分母的平方。为什么天然分两种情况?看分子:分子是 e^{zᵢ},只有当求导变量恰好是 zᵢ(即 i=j)时,分子才含 z、才有导数;分母 S = Σₖ e^{zₖ} 却不挑人——不管你动哪个 zⱼ,它都含着 e^{zⱼ},分母永远要参与求导。于是 i=j 时分子分母齐上场,i≠j 时分子"请假"(导数为 0),只剩分母拖后腿:

yᵢ = e^{zᵢ} / Σₖ e^{zₖ} = e^{zᵢ} / S

# 情况 1: i = j(对自身求导,商式法则)
∂yᵢ/∂zᵢ = e^{zᵢ}/S − e^{zᵢ}·e^{zᵢ}/S²
         = yᵢ − yᵢ² = yᵢ(1 − yᵢ)

# 情况 2: i ≠ j(分子不含 zⱼ,只有分母含)
∂yᵢ/∂zⱼ = 0 − e^{zᵢ}·e^{zⱼ}/S² = − yᵢ·yⱼ

# 统一写(δᵢⱼ 为 Kronecker delta:i=j 为 1,否则 0)
∂yᵢ/∂zⱼ = yᵢ · (δᵢⱼ − yⱼ)

推完别急着交卷,把结果读一遍、对上直觉:i=j 时 ∂yᵢ/∂zᵢ = yᵢ(1−yᵢ) 恒为正——自己动,自己涨;它在 yᵢ = 0.5 时最大(势均力敌时最敏感),在 yᵢ 趋近 0 或 1 时趋近 0(一边倒时再推也纹丝不动——这是"饱和"的伏笔,追问里会考)。i≠j 时 −yᵢyⱼ 恒为负——别人动,我必跌,跌幅恰好是两人份额的乘积。δᵢⱼ(Kronecker delta)像个开关:i=j 取 1、否则取 0,把两种情况合并成一行公式——深度学习框架里手写 softmax 反向传播时,抄的就是这一行。

3. 拼成矩阵看:一张 K×K 的"影响面分析表"

把所有 ∂yᵢ/∂zⱼ 按"行是输出、列是输入"摆开,就是雅可比矩阵 J,可以紧凑写成 J = diag(y) − y·yᵀ:

            z₁          z₂          z₃
y₁  [   y₁(1−y₁)     −y₁y₂       −y₁y₃   ]
y₂  [    −y₂y₁      y₂(1−y₂)     −y₂y₃   ]
y₃  [    −y₃y₁       −y₃y₂      y₃(1−y₃) ]

对角线:自己动、自己涨(正)   非对角:别人动、自己跌(负)
没有一格是空的 → 稠密耦合 → 这就是"非对角不为 0"的矩阵证据

拿一组真实数字走一遍(z = (2, 1, 0)):先算出 y ≈ (0.665, 0.245, 0.090),再逐格填表:

偏导∂/∂z₁∂/∂z₂∂/∂z₃行和
对 y₁(份额 0.665)+0.223−0.163−0.0600
对 y₂(份额 0.245)−0.163+0.185−0.0220
对 y₃(份额 0.090)−0.060−0.022+0.0820

重点盯"行和"这一列:任何一行的偏导加起来正好是 0。一行公式就能证明:Σⱼ ∂yᵢ/∂zⱼ = yᵢ·(Σⱼδᵢⱼ − Σⱼyⱼ) = yᵢ·(1 − 1) = 0。翻译成人话:所有输入一起抬高同样的量,概率分布纹丝不动——即 softmax(z + c) = softmax(z),平移不变性。记住它,第 4 步的数值稳定技巧全靠这条撑腰;面试里能把"行和为零"和"减 max 合法"串成一条线讲出来,就是超出背书水平的信号。

4. 两个实用推论

  • 与 CE 合体:L = −Σₖ tₖ·log yₖ,链式法则可得 ∂L/∂zᵢ = yᵢ − tᵢ(one-hot t)。推导:∂L/∂zᵢ = Σⱼ(−tⱼ/yⱼ)·yⱼ(δⱼᵢ−yᵢ) = yᵢ − tᵢ。这是所有分类框架的标配,数值稳定。把中间那行慢放一遍:① L 通过全部 y 依赖 z,而每个 yⱼ 又依赖所有 zᵢ,所以 j 要从头加到尾(链式法则 + 求和规则);② 对 yⱼ 求导得 −tⱼ/yⱼ(log 求导留下的 1/y);③ 乘上第 2 步推好的 yⱼ(δⱼᵢ−yᵢ),yⱼ 当场约掉——损失里的 log 正好拆了 softmax 里 exp 的台;④ one-hot 的 t 只有一项非零,Σⱼtⱼδⱼᵢ = tᵢ、Σⱼtⱼ = 1,收尾得 yᵢ − tᵢ。整场推导里最贵的 log 和 exp 一照面就同归于尽,只剩"预测减真值"——输出层的梯度就是误差信号本身:预测过头往回拉,预测不足往前推,代码三行搞定。
  • 数值稳定:实际先减 max(z),即 yᵢ = exp(zᵢ−m)/Σₖ exp(zₖ−m),结果不变,避免 exp 溢出。为什么必须减:float64 上限约 1.8×10³⁰⁸,exp(710) 直接溢出成 inf,z 只要冲上 1000,softmax 整体算出 NaN,训练当场炸——和你写后台防整数溢出是同一种职业本能。为什么敢减:分子分母同除一个 exp(m),各家占比一个不差,靠的就是第 3 步证的平移不变性;减完之后所有指数都落在非正数区间,最大那项是 exp(0) = 1,分母永远至少为 1——既不溢出,也不会除以接近 0 的数。类比:所有报价同减一个基准价,各家占比不变,但数字从天文数字落回日常量级。

5. 为什么面试爱考

  • 检验链式法则基本功,以及是否理解 softmax 是"耦合的"(雅可比矩阵非对角不为 0)。
  • 这道题还能顺着往工程挖:知不知道减 max 防溢出?知不知道饱和导致梯度消失?背结论的人和真推过的人,追问两层就现原形。
面试官追问
Q:Softmax 的雅可比矩阵长什么样?
人话:一张 K×K 敏感度表:对角线是 yᵢ(1−yᵢ)(自己动自己涨),其余格全是 −yᵢyⱼ(别人动我必跌),没有一格空着,一行公式写完:J = diag(y) − y·yᵀ。类比:像配置变更的影响面表——普通层是稀疏对角阵、各管各的;Softmax 共享分母,整表满格,动一处、全体跟着重新分账。技术:J 是 K×K 方阵,对角元 yᵢ(1−yᵢ),非对角元 −yᵢyⱼ;当 y 接近 one-hot 时对角元也趋 0,整个矩阵趋近零矩阵——对应 softmax 饱和区的梯度消失,矩阵形态就是"预测过于自信、模型学不动"。
Q:为什么 Softmax+CE 的梯度是 y−t,不是更复杂的形式?
人话:CE 里埋了个 log,softmax 里埋了个 exp,互为反函数的两位一照面就抵消,复杂成分全约光,只剩"预测减真值"。类比:像先做备份再立刻恢复——两步互逆等于白干,剩下的只有数据本身;设计 CE 的人等于提前在损失里备好了解药。技术:∂L/∂yⱼ = −tⱼ/yⱼ,乘上 ∂yⱼ/∂zᵢ = yⱼ(δⱼᵢ−yᵢ) 后 yⱼ 当场约掉,对 j 求和时 one-hot 只剩一项,得 ∂L/∂zᵢ = yᵢ − tᵢ。梯度就是误差信号本身:不除小数、不炸数值、实现三行——这是它成为所有分类框架标配的原因。
Q:Softmax 会梯度消失吗?
人话:会。某个分数把别人甩开太远时,概率一家独大,梯度 yᵢ(1−yᵢ) 里的 (1−yᵢ) 趋 0,推不动了——这就是饱和。类比:像容灾切换,一旦主节点扛下 100% 流量,再调高它的权重,流量分布纹丝不动;想让系统重新响应,得等"比分"重新接近。技术:单独看 softmax,zᵢ 远大于其他分量时 yᵢ→1,对角元 yᵢ(1−yᵢ)→0,该方向梯度趋 0(饱和)。但配 CE 后输出层梯度是 y−t,只取决于预测和真值的差距,不因 softmax 饱和而消失——所以实践中几乎总是 softmax+CE 连用,不分开算梯度。
Q:LLM 采样里的温度参数 T 和 Softmax 是什么关系?
人话:大模型生成就是给每个候选词算一遍 softmax 概率再按概率抽签;温度 T 是除在分数上的旋钮——T 调小,概率向最高分集中、输出保守;T 调大,概率摊平、输出放飞。类比:像负载均衡的激进程度旋钮:T 趋近 0 是 all-in 最优节点,T 很大是彻底摊大饼。技术:采样公式 yᵢ = exp(zᵢ/T)/Σₖ exp(zₖ/T)。T→0 退化为 argmax(必选最高分,正好落在上面说的饱和区),T→∞ 趋近均匀分布 1/K。调 T 就是在确定性与多样性之间滑动,Agent 场景求稳定一般取 0~1。
术语卡
Logits:softmax 前的原始分数向量 z,可正可负、没有上下界。
Kronecker delta(δᵢⱼ):i=j 为 1,否则为 0——把"分情况讨论"合并成一行的开关。
雅可比矩阵:输出对输入的全部一阶偏导组成的矩阵,本题里就是那张 K×K 影响面表。
数值稳定:减去 max(z) 防止 exp 溢出——不改数学结果,只防计算机翻车。
交叉熵(CE):分类任务的标准损失,内置 log,专与 softmax 的 exp 配对抵消。
梯度消失:概率被推向极端后雅可比趋零、模型学不动——softmax 饱和区是一例。
