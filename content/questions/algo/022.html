推导 Softmax 的梯度

⭐⭐⭐ #Softmax#梯度#数学推导 无公司
30秒电梯稿

"Softmax 把 logits 变成概率分布 y = softmax(z)。它的梯度有个漂亮的结果:∂yᵢ/∂zⱼ = yᵢ(δᵢⱼ − yⱼ),即对角元是 yᵢ(1−yᵢ)、非对角元是 −yᵢyⱼ。推导只需对商式求导,分 i=j 和 i≠j 两种情况。更实用的推论是:Softmax + 交叉熵合起来,梯度退化成 y − t,实现和推导都极简,这也是所有分类框架的标准写法。"

通俗类比

把 Softmax 想象成"抢红包分钱":原始 logits 是大家手里的本金,softmax 把本金按指数换算成"中奖概率"。梯度问的是:某人的本金 zⱼ 增加一点,第 i 个人分到的概率 yᵢ 怎么变?直觉是——改的是自己(i=j),自己概率上涨;改的是别人(i≠j),因为总概率恒等于 1,别人的上涨必然挤占我的份额,所以是负的。这就是 δᵢⱼ 那一项的含义。

详细拆解

1. 定义与性质

  • 设 z = (z₁,…,z_K),S = Σₖ exp(zₖ),则 yᵢ = exp(zᵢ)/S。
  • 性质:Σ yᵢ = 1、非负、单调(zᵢ 增 → yᵢ 增)。注意每个 yᵢ 依赖所有 z 分量,这是"耦合"的来源。

2. 分情况推导

yᵢ = e^{zᵢ} / Σₖ e^{zₖ} = e^{zᵢ} / S

# 情况 1: i = j(对自身求导,商式法则)
∂yᵢ/∂zᵢ = e^{zᵢ}/S − e^{zᵢ}·e^{zᵢ}/S²
         = yᵢ − yᵢ² = yᵢ(1 − yᵢ)

# 情况 2: i ≠ j(分子不含 zⱼ,只有分母含)
∂yᵢ/∂zⱼ = 0 − e^{zᵢ}·e^{zⱼ}/S² = − yᵢ·yⱼ

# 统一写(δᵢⱼ 为 Kronecker delta:i=j 为 1,否则 0)
∂yᵢ/∂zⱼ = yᵢ · (δᵢⱼ − yⱼ)

3. 两个实用推论

  • 与 CE 合体:L = −Σₖ tₖ·log yₖ,链式法则可得 ∂L/∂zᵢ = yᵢ − tᵢ(one-hot t)。推导:∂L/∂zᵢ = Σⱼ(−tⱼ/yⱼ)·yⱼ(δⱼᵢ−yᵢ) = yᵢ − tᵢ。这是所有分类框架的标配,数值稳定。
  • 数值稳定:实际先减 max(z),即 yᵢ = exp(zᵢ−m)/Σₖ exp(zₖ−m),结果不变,避免 exp 溢出。

4. 为什么面试爱考

  • 检验链式法则基本功,以及是否理解 softmax 是"耦合的"(雅可比矩阵非对角不为 0)。
面试官追问
Q:Softmax 的雅可比矩阵长什么样?
J 是 K×K 方阵,对角元 yᵢ(1−yᵢ),非对角元 −yᵢyⱼ,可写成 J = diag(y) − y·yᵀ。注意当 y 接近 one-hot 时,对角元趋近 0,雅可比趋近 0 矩阵——对应 softmax 饱和区的梯度消失。
Q:为什么 Softmax+CE 的梯度是 y−t,不是更复杂的形式?
因为 log 和 exp 互为反函数,链式求导时指数和对数相互抵消,最后只剩线性项 y−t。这也是交叉熵配 softmax 成为标配的原因之一:梯度简洁、数值稳定、实现不容易出错。
Q:Softmax 会梯度消失吗?
单独看 softmax,当某个 zᵢ 远大于其他分量时 yᵢ→1,对角元 yᵢ(1−yᵢ)→0,该方向梯度趋近 0(饱和)。但配 CE 后,输出层梯度 y−t 不会因此消失——所以实践中几乎总是 softmax+CE 连用,而不是分开算梯度。
术语卡
Logits:softmax 前的原始分数向量 z。
Kronecker delta(δᵢⱼ):i=j 为 1,否则为 0。
雅可比矩阵:输出对输入的全部一阶偏导组成的矩阵。
数值稳定:减去 max(z) 防止 exp 溢出。
