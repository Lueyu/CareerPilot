推导 Cross-Entropy Loss 与 Negative Log-Likelihood 的关系

⭐⭐⭐ #损失函数#理论推导 无公司
30秒电梯稿

"交叉熵损失和负对数似然在分类任务里是同一个东西。NLL = −log y_true,只取真实类别概率的负对数;交叉熵 CE = −Σ tᵢ·log yᵢ,当标签是 one-hot 时,求和里只有真实类那一项非零,所以 CE = NLL,严格相等。两者的本质都是极大似然估计(MLE):最小化 NLL/CE 等价于最大化模型在数据上的似然。"

通俗类比

想象你在猜骰子:模型对每个面给一个概率,真实结果是"3 点"。负对数似然说:"我只关心模型给 3 点那个面的概率,越低我罚得越重"。交叉熵说:"我把真实分布(3 点是 100%、其他面 0%)和模型预测分布逐面对比"。因为真实分布只有 3 点那一面是 1、其余全是 0,逐面对比下来,最后也只剩 3 点那一项在起作用——所以两者算出来的数一模一样。

详细拆解

1. 两个定义

  • 交叉熵:CE(p, q) = −Σ p(x)·log q(x),p 是真实分布,q 是模型预测分布。
  • 负对数似然(NLL):NLL = −log q(y|x),y 是真实标签,q(y|x) 是模型给该标签的概率。

2. 等价性推导

# 设真实标签为 one-hot: t = (0,…,1,…,0), 真实类为 c, 即 t_c = 1
# 模型输出概率分布: y = (y₁,…,y_K), Σᵢ yᵢ = 1

交叉熵:   CE = − Σᵢ tᵢ · log yᵢ = − log y_c      (只有 i=c 项非零)
负对数似然: NLL = − log P_θ(y=c | x) = − log y_c

∴ CE = NLL    (分类 + one-hot 标签下严格相等)

3. 与极大似然估计(MLE)的关系

  • 样本似然 L = Π q(xᵢ);对数似然 log L = Σ log q(xᵢ)。
  • 最大化 log-likelihood ⇔ 最小化 −Σ log q(xᵢ) ⇔ 最小化 NLL ⇔ 最小化 CE。
  • 结论:用交叉熵训练分类器,本质就是在做极大似然估计。

4. 什么时候不再相等(边界)

  • 标签非 one-hot(标签平滑、软标签、知识蒸馏)时,CE = −Σ tᵢ·log yᵢ 仍成立,但不能再简化成单个 −log y_c,此时 CE 是软标签下的期望 NLL。
  • 二分类特例:BCE = −[ t·log y + (1−t)·log(1−y) ]。
  • 严格说,NLL 是 CE 在 one-hot 标签下的特例;CE 是更一般的定义。
面试官追问
Q:为什么分类不用 MSE,而用交叉熵?
两层原因:① 交叉熵配 softmax 梯度为 y−t,简洁且不饱和;MSE 配 softmax 会多出 y(1−y) 因子,输出接近 0/1 时梯度消失、学得慢。② 概率视角下 MSE 假设误差服从高斯分布,而分类标签是类别分布,交叉熵才是与 Bernoulli/Categorical 分布匹配的 MLE 目标。
Q:用了标签平滑之后,CE 和 NLL 还相等吗?
不等。标签平滑把 t 从 one-hot 改成 t_c = 1−ε、其余 ε/(K−1),此时 CE = −Σ tᵢ·log yᵢ 是软标签下的期望,无法再简化成单个 −log y_c。这正好说明 NLL(单点形式)只是 CE 在 one-hot 下的特例,CE 更一般。
Q:多标签分类(一条样本多个标签)能用 softmax+CE 吗?
不能直接。softmax 假设标签互斥(总和为 1 的单标签),多标签场景应改用 sigmoid + BCE:每个标签独立做二分类,损失为各标签 BCE 之和。这道题常用来测候选人是否理解损失函数背后的"分布假设"。
术语卡
交叉熵(CE):真实分布与预测分布差异的期望信息量。
负对数似然(NLL):真实类别概率取负对数。
MLE:极大似然估计,选参数使观测数据概率最大。
one-hot:唯一位置为 1、其余为 0 的标签编码。
标签平滑:把 one-hot 软化,抑制过拟合。
