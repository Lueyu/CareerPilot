推导 Contrastive Loss(CLIP)的梯度

⭐⭐⭐⭐ #ContrastiveLoss#CLIP#梯度推导
先说人话:这题不是让你背 CLIP 的论文，而是当场手推一个 softmax 分类的梯度——本质是"多分类交叉熵的梯度长什么样"换个皮。面试官爱考它，是因为一推就知道你是"背过 loss 公式"还是"真懂反传"；答错的暴露点几乎总在同一个地方：忘了 softmax 的经典结论 ∂L/∂logit = p − y，然后硬去对 exp 求导，推十分钟推不完。你写过反向传播、调过 loss 的手感，这题其实是你的舒适区。
30秒电梯稿

"CLIP 用的是对称 InfoNCE 损失：一个 batch 里 N 对图文，图像当 query、文本当候选做 softmax 分类，反过来再算一遍，两方向取平均。梯度推导的关键一步是softmax 的经典结论：∂L/∂logit = p − y——正确对（p 对角线上）的梯度是 (p_ii − 1)，是负的、把正确相似度往上拉；其余负样本的梯度是 p_ij，正的、把负样本往下推，且权重等于它当前被选中的概率——越"难"的负样本被压得越狠。回传到 embedding 上，梯度方向 = 拉近匹配文本、推开"所有文本的 softmax 加权平均"."

通俗类比

InfoNCE 损失(用"备份系统的数据校验"想)：你有一批备份数据块，每个数据块只对应唯一的一份元数据（metadata），校验时要求"每个数据块只认领自己那一份元数据，不能认领别人的"。CLIP 训练时，一张图片要在一堆文本描述里认出自己配对的那句，softmax 给每句描述打一个"是我的可能性"分。认错得越严重的描述（hard negative，难负样本），罚得越狠——就像数据校验里最容易跟目标块混淆的"近似重复块"，恰恰是最要重点区分的。

温度 τ(用"告警阈值"想)：τ 相当于告警系统的灵敏度旋钮。τ 小 = 阈值卡得极严，softmax 输出接近非黑即白，梯度大、对比"硬"；τ 大 = 一团和气，梯度平、学不动。哪里像：都是控制"区分度 vs 稳定性"的折中。哪里不像：告警阈值是拍脑袋定的，CLIP 里的 τ 是可学习参数，模型自己调灵敏度。

L2 归一化(用"容量规划只看占比不看绝对量"想)：把 embedding 模长压成 1，相似度就变成余弦相似度，落在 [−1,1]。哪里像：删掉一个无关自由度，让系统专注学"方向"而不是"规模"。哪里不像：容量规划是运维约束，归一化是有梯度效果的——归一化层的 Jacobian 会把梯度投到球面切平面上（后面细讲），不是简单裁剪。

梯度公式 p − y(用"流式备份的纠偏"想)：每次校验后，系统不搞一刀切，而是按"当前误配概率"分配纠正力度——最像的错配推得最用力。哪里像：错误越严重权重越大；哪里不像：这里"力度"是连续概率权重，不是离散重试次数。

详细拆解

1. 先建立大局观：这题只是"交叉熵 + softmax"的变装

很多同学一看到"对比学习""CLIP"就发怵，其实把符号摆开你会发现：图像 uᵢ 在 N 个文本 {vⱼ} 上做一个 N 类分类，正确类别是第 i 类——这就是最普通的多分类交叉熵。你过去手推过 softmax 交叉熵梯度的话，这题你已经会了 80%。剩下的 20% 只有两点新增：① 相似度是内积/τ，链式法则多一环；② 损失要"图像→文本"和"文本→图像"各算一遍取平均。

普通多分类交叉熵CLIP 的 InfoNCE
logit 来源全连接层 Wx + b归一化向量的内积 uᵢᵀvⱼ / τ
类别数固定的类别集合batch 内的 N 句文本（每个 batch 变）
正确类别标签指定第 i 句（自己的配对文本）
对称性单向双向对称：图像→文本 + 文本→图像
logit 对参数的梯度∂L/∂logit = p − y完全一样：p_ij − δ_ij

2. 符号设定

  • batch 含 N 对 (图像 xᵢ, 文本 yᵢ)，i = 1…N。注意这里的 N 类比成"一次校验批里的 N 个数据块"，batch 内互为负样本。
  • 编码器输出先做 L2 归一化到单位球：uᵢ = f_img(xᵢ)/‖f_img(xᵢ)‖，vⱼ = f_txt(yⱼ)/‖f_txt(yⱼ)‖。归一化后内积 = 余弦相似度。
  • 相似度矩阵(含温度)：L_ij = uᵢᵀvⱼ / τ，τ 为可学习温度(CLIP 初始化约 0.07)。τ 除在 logit 上，等价于把 [−1,1] 的余弦值放大成有区分度的分数。

3. 对称 InfoNCE 损失

L_img = −(1/N) Σᵢ log [ exp(L_ii) / Σⱼ exp(L_ij) ]   # 图像→文本方向:每行一个 softmax,正确标签是 i
L_txt = −(1/N) Σⱼ log [ exp(L_jj) / Σᵢ exp(L_ij) ]   # 文本→图像方向:每列一个 softmax
L     = ½ (L_img + L_txt)                            # 对称取平均

只看 L_img 时，整个 N×N 矩阵可以画成一张"配对校验表"，行是图像、列是文本，对角线是正确配对，我们要的分布是"概率质量全压到对角线上"：

          文本v₁   文本v₂   文本v₃  ...  文本v_N
图像u₁  [ ✔p₁₁     p₁₂     p₁₃   ...   p₁N ]   ← 期望:[1, 0, 0, ..., 0]
图像u₂  [  p₂₁    ✔p₂₂     p₂₃   ...   p₂N ]
图像u₃  [  p₃₁     p₃₂    ✔p₃₃   ...   p₃N ]
  ...
图像u_N [  p_N1     p_N2     p_N3   ...  ✔pNN ]

梯度 ∂L/∂L_ij = p_ij − δ_ij:
  对角线(正样本) → p_ii − 1 ≤ 0   往上拉(增相似度)
  非对角(负样本) → p_ij    ≥ 0    往下推(降相似度)
  推力大小 = 该负样本当前被误选中的概率

4. 核心步骤：softmax 对 logit 的梯度

固定第 i 行，定义该行的 softmax 概率 p_ij = exp(L_ij) / Σₖ exp(L_ik)，行损失 L_img⁽ⁱ⁾ = −log p_ii = −L_ii + log Σₖ exp(L_ik)。对任意 logit L_ij 求偏导（这里请务必一步一步走，面试官就是看你这一步稳不稳）：

先展开两项各自的导数：−L_ii 对 L_ij 的导数是 −δ_ij；log Σₖ exp(L_ik) 对 L_ij 的导数，按链式法则 = (1/Σₖ exp(L_ik)) · exp(L_ij) = p_ij。两者相加：

∂L_img⁽ⁱ⁾ / ∂L_ij = −δ_ij + exp(L_ij)/Σₖ exp(L_ik)
                  = p_ij − δ_ij          # δ_ij:j=i 时为 1,否则 0
  • 正样本对(i,i)：梯度 = p_ii − 1 ≤ 0，即"把正确相似度往上拉"，且当前置信度越低(p_ii 越小)，拉力越大——完全符合直觉：越没把握的配对，越要使劲学。
  • 负样本对(i,j≠i)：梯度 = p_ij ≥ 0，即"把负样本往下推"，推力正比于它当前被误选的软概率——hard negative 梯度更大。这就是类比里说的"最像的错配块重点区分"。
  • 写成矩阵就是 L_img 对 logit 矩阵 L 的梯度 = (P − I)/N，P 为逐行 softmax 后的概率矩阵。注意每一行的梯度加起来为 Σⱼ(p_ij − δ_ij) = 1 − 1 = 0，梯度行和为零——纯"重新分配"不加不减，这也是对比学习不会有系统性"把所有分数一起推高/压低"的原因。

5. 回传到 embedding(链式法则)

logit 是 L_ij = uᵢᵀvⱼ / τ，所以对两个归一化向量的导数极其干净：

∂L_ij/∂uᵢ = vⱼ/τ ,  ∂L_ij/∂vⱼ = uᵢ/τ

把第 4 步的 (p_ij − δ_ij) 当系数、对所有 j 求和，就得到图像 embedding 的总梯度：

∂L_img/∂uᵢ = (1/τ) Σⱼ (p_ij − δ_ij) vⱼ
            = (1/τ)( Σⱼ p_ij vⱼ − vᵢ )     # 推开的是"所有文本的 softmax 加权平均"
  • 直观解读这个式子：梯度下降更新 uᵢ 时，减去的量 = (1/τ)(文本质心 Σⱼ p_ij vⱼ − 配对文本 vᵢ)。等价于把 uᵢ 往配对文本 vᵢ 拉近，同时远离"按 p_ij 加权的软文本质心"。p_ij 大的文本（hard negative）在质心里权重大，被推离得最远。文本方向对称同理。
  • 温度 τ 出现在 1/τ 系数里：τ 越小，softmax 越陡、梯度越大，对比越"硬"，模型集中火力打难样本，但打过头会数值不稳定；τ 越大越"软"、梯度平、学习慢。这是 τ 也参与学习的原因——训练早期需要软一点均匀探索，后期需要硬一点聚焦难样本，一个可学习的 τ 自动完成这个调度。

6. 进阶细节：归一化层的 Jacobian

  • 若继续反传到归一化前的特征 a(令 u = a/‖a‖)，则 ∂u/∂a = (I − uuᵀ)/‖a‖。
  • 这一项把梯度投影到单位球的切平面，保证更新后仍"贴近"球面，梯度不会沿径向白白浪费。用类比说：归一化像把所有服务器规格"定死成同一种机型"，任何想改变"机型大小"（模长）的梯度分量都会被投影抹掉，只保留"调整部署方向"（切向）的部分——模型只能学方向，学不了"变大变小"。

7. 理论意义(一句话)

InfoNCE 是互信息的下界:I(u;v) ≥ log N − L_InfoNCE。因此最小化该损失,等价于最大化图像与文本表示互信息的下界——这也是 CLIP 能让图文语义对齐到同一空间的理论依据。注意下界里的 log N：batch 越大下界越紧，这就把第 8 条追问"batch size 为什么关键"从理论上焊死了。

面试官追问
Q:为什么 CLIP 要对称地算两个方向,单方向不行吗?
人话:单方向相当于只考了图片认文本这一半题,文本认图片那一半没考,两边的难度都要被建模。类比:这就像备份系统只校验"数据块→元数据"方向,不校验"元数据→数据块",一条链路对齐了,另一条链路的漂移你看不见;双向校验才能保证两个索引体系严格一一对应。技术:单向只把"图像做 query"的 softmax 用上,文本侧的区分难度没被显式建模;对称损失让两塔被等强度地拉齐,训练更稳定、对齐更对称。实践中也有单向变体(如 SimCLR 用同构增广两视角),但图文双塔场景通常对称更好——CLIP 论文消融也验证了对称损失优于单向。
Q:温度 τ 在这里起什么作用?为什么它也参与训练?
人话:τ 是对比强度的灵敏度旋钮,控制 softmax 多"尖"以及梯度整体放大多少倍(1/τ)。类比:像备份巡检的告警阈值:卡太严(τ 小)只有最严重的故障才报警,火力集中但容易误伤和数值不稳;卡太松(τ 大)什么都报警等于没报,梯度太平学不动。技术:τ 太小→分布接近 one-hot、只学极难样本、数值不稳定;τ 太大→梯度太平、学不动。让 τ 可学习,模型自适应地找最优对比强度——CLIP 训练完 τ 通常从 0.07 降到 0.02 左右,说明模型后期主动"加严阈值"聚焦 hard negative,免去人工调参。
Q:batch size 对对比学习为什么这么关键?
人话:负样本全部来自同一个 batch,batch 越大"陪练"越多、题目越难,学出来的表示越有区分度。类比:这就像容灾演练:只拉 3 台机器做故障注入,场景太少;拉 100 台,各种稀奇古怪的故障组合都见过,系统才真正抗造。负样本池就是"演练场景库"。技术:InfoNCE 的互信息下界是 log N − L,N 越大下界越紧;batch 越大负样本越多样、表示越好,但显存压力也越大。所以才有 memory bank、MoCo 的动量队列(把旧 batch 的编码存起来循环利用)、SimCLR 的大 batch 等"扩大负样本池"的工程手段。
Q:L2 归一化 + 内积,和直接用点积比有什么好处?
人话:归一化后所有向量模长都为 1,分数只看"方向合不合",不看"声音大不大"。类比:像容量规划只看占比、不看绝对量:一个服务把资源翻倍不代表它更重要,归一化就是把"虚胖"的表示压回同一起跑线,防止模型靠增大模长刷分。技术:归一化后相似度变成余弦相似度,数值落在 [−1,1],训练对特征尺度不敏感、更稳定;同时去掉模长这个无关自由度,让模型专注学方向——对跨模态对齐尤其重要,因为图像和文本特征天然处于不同尺度的空间,不归一化时内积会被一侧的模长主导。代价是归一化层 Jacobian 多一层计算,且丢失模长携带的少量信息(通常可忽略)。
Q:面试现场如果忘了 p − y 这个结论,怎么现场重推出来?
人话:别硬背结论,记住"拆成两项分头求导"的路子,30 秒能现推。类比:就像排障不背 runbook,先拆链路:从 L 到 logit 的链路就两段——交叉熵到概率、概率到 logit,一段一段查。技术:把行损失写成 L_img⁽ⁱ⁾ = −L_ii + log Σₖ exp(L_ik),第一项求导得 −δ_ij,第二项按链式法则得 (1/Σ)·exp(L_ij) = p_ij,相加即 p_ij − δ_ij。整个推导只需要链式法则和"exp 的导数还是 exp"两个事实,没有一步需要记忆力——这正是面试官想看到的:你不是背的,你是会推的。
术语卡
InfoNCE:基于 softmax 的对比损失,是图像与文本表示互信息的下界。
Hard negative:与正样本易混淆的负样本,在 p − y 梯度公式里权重最大、贡献最大。
双塔结构:图像、文本两个独立编码器,输出归一化后在末端对齐,便于离线预计算向量检索。
温度 τ:缩放 logit 的可学习参数,控制 softmax 锐度与梯度尺度(1/τ)。
MoCo:用动量队列扩大负样本池的对比学习框架,缓解 batch size 瓶颈。
CLIP:OpenAI 的图文对比预训练模型,4 亿图文对上学出通用零样本视觉能力。
