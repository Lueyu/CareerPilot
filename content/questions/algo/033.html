Llama 3 的训练技巧

⭐⭐⭐ #论文解读#Llama3#训练
30秒电梯稿

Llama 3 的训练技巧我总结成三条:① 数据规模与配比——预训练数据从 Llama 2 的约 2T 冲到约 15T tokens,并刻意配比(通用知识约一半、数学推理约四分之一、代码约 17%、多语言约 8%),清洗去重做得很重;② 训练稳定性——在 15T 规模下全程没有灾难性 loss 尖峰,靠谨慎的超参与数据工程;③ 长上下文——先用 8K 预训练,再分阶段续训逐步拉长到 128K,配合 RoPE 频率调整。架构上全系 GQA、词表扩到 128K,后训练改用 SFT + DPO 而非 PPO。

通俗类比

像给学霸设计一整套备考计划:① 教材怎么选——不再只刷一本习题集(2T),而是 15 个 T 的海量题库,各科配比精确:一半综合、四分之一数学推理、不到两成编程、再加一点外语;② 怎么保证刷题不崩——15T 道题刷下来一次都不"学崩"(loss 不爆炸),靠稳扎稳打的节奏;③ 怎么延长专注时长——从 8K 的专注度,分阶段加练到 128K,而不是一上来就逼他读超长文。

详细拆解

1. 数据规模与配比(质量 + 数量双管齐下)

  • 预训练数据从 Llama 2 的约 2T 提升到约 15T tokens——规模扩张是能力提升的底座。
  • 刻意配比(据论文,大致比例):通用知识约 50%、数学与推理约 25%、代码约 17%、多语言约 8%——通过调高数学/代码占比,直接拉升推理与代码能力。
  • 质量工程:去重、质量过滤、启发式与基于模型的清洗,让"更多数据"不等于"更多噪声"。

2. 训练稳定性(大规模训练的核心工程能力)

  • 15T 级别的训练最容易出"loss 尖峰 / 发散"事故,一旦炸了很难救。Llama 3 在长训练中保持稳定,没有灾难性发散。
  • 手段方向:谨慎的初始学习率与 warm-up、数据质量把关、监控与 checkpoint 机制等(论文未逐条公开所有超参,但稳定性是明确强调的成果)。
  • 面试要传递的认知:能训大模型不是"跑得动",而是"跑得稳、能恢复"。

3. 长上下文扩展(分阶段续训,而非一步到位)

  • 关键认知:长上下文是"续训"出来的,不是改个位置编码超参就生效;分阶段渐进扩展比一次跳到 128K 更稳。
  • 通过提高 RoPE 基频,把"可分辨的长距离位置"范围扩上去,避免直接外推带来的质量塌陷。

4. 架构与后训练(顺手答全)

  • 架构:全系 GQA(省 KV cache)+ 词表扩到约 128K(更省 token)。
  • 后训练:从上一代的 PPO/RLHF 转向 拒绝采样 + SFT + DPO,实现更简单、更稳,同样能对齐偏好。

面试话术:数据配比的具体百分比引用论文的"约值"即可,重点是能讲出"为什么要调高数学/代码占比""为什么分阶段扩上下文""DPO 相对 PPO 的工程收益"这三个 why。

面试官追问
Q:为什么要把数学和代码的占比调高?
因为这两类语料是"高信息密度、强逻辑结构"的——模型从中能学到推理、格式、符号操纵能力,而不仅是语言流畅。数据配比直接决定能力分布:通用文本堆再多也只是"更会聊天",想拉升代码/数学能力,就得在训练分布里提高它们的权重。
Q:训练中 loss 尖峰了怎么处理?
分层:① 预防——数据去重与质量过滤、合适的学习率调度;② 检测——训练监控,发现 loss 异常上升;③ 恢复——回滚到最近的健康 checkpoint,调整数据/超参后重训(可能要跳过疑似脏数据批次)。大规模训练最贵的是"训练到一半崩了",所以 checkpoint 与监控体系是命根子。
Q:为什么用 DPO 替代 PPO?
PPO 要同时维护策略模型、参考模型、奖励模型、价值模型四套东西,训练不稳定、超参敏感、显存开销大;DPO 把偏好对齐直接做成一个可微的分类损失,只用一个策略模型 + 参考模型,实现简单、更稳、成本低,还绕开了奖励模型漂移的问题。代价是对偏好数据的质量和覆盖要求更高。
Q:直接一步把上下文拉到 128K 为什么不行?
位置编码的 RoPE 基频是为预训练长度调的,直接拉长会让长距离位置"超界",模型对长位置失去分辨能力、质量骤降。所以要分阶段续训:逐步提高 RoPE 基频、逐步加长训练序列,让模型在长窗口上重新学到注意力分布,才会稳定。
术语卡
数据配比:不同领域语料在预训练数据中的占比。
Loss 尖峰:训练中 loss 突然异常升高,可能引发发散。
长上下文续训:在更长序列上继续预训练以扩展窗口。
DPO:直接偏好优化,绕过奖励模型做偏好对齐。
RoPE 基频:旋转位置编码中控制位置分辨尺度的超参。
