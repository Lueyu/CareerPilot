设计 VLM 幻觉问题的评估实验

⭐⭐⭐⭐ #VLM#幻觉#实验设计
30秒电梯稿

"VLM 幻觉评估我按『五类幻觉 + 探测式数据集 + 双指标』搭:① 幻觉类型分对象存在、属性、关系、计数、OCR 文本五类;② 数据集用 POPE 式『图像+一句断言,答 yes/no』,正负样本 1:1 配平,负样本来自对真图像做『对象不存在/改属性』的反事实扰动,答案已知可判定;③ 指标报 yes-准确率、精确率/召回率/F1,并单独看『不该答 yes 却答了』的假阳性率(幻觉核心);④ 对照组:强模型/人工标注上界、盲评;⑤ 消融:提示(加不加 CoT)、分辨率、解码温度,横向对比不同模型。"

通俗类比

就像让一个爱吹牛的讲解员看图说话:图里只有一只猫,他硬说还有条狗(对象幻觉)、说猫在飞(关系幻觉)。评估就是准备好一批"标准答案已知"的图,专门问他"图里有狗吗?""猫是飞的吗?",统计他把"没有"说成"有"的次数——这就是吹牛率。

详细拆解

1. 先定"可判定"的幻觉类型(评估前提是答案有 ground-truth)

  • 五类:对象存在(图里没有的物体)、属性(颜色/材质/大小说错)、关系(空间/动作关系错)、计数(数量数错)、OCR 文本(读错文字)。
  • 只做这些"对错明确"的场景,不做"描述得好不好"这类主观题,否则无法自动、可复现地打分。

2. 数据集构建(四步)

  • 选图:MSCOCO / GQA / 文档图等有标注的图像。
  • 造断言:正样本 = 图里真实成立的事实;负样本 = 反事实(随机替换对象、改属性、改关系、改数量),保证"是假"。
  • 配平与分层:正负 1:1,并按对象类别、罕见对象、小目标/遮挡分层,避免模型靠"高频对象一定在"猜对。
  • 人工复核:抽验负样本确实为假、正样本确实为真,控制标注噪声。

3. 指标:精确率/召回率 + 假阳性率

指标含义说明
yes-准确率正负整体判对比例粗看够,细看不够
精确率 / 召回率 / F1答 yes 里有多少真 yes;真 yes 里答对多少精确率低=爱瞎说有
假阳性率(幻觉率)负样本被答 yes 的比例幻觉核心指标,越低越好
拒答率模型"不答/说看不清"的比例单独统计,别和"答错"混

4. 对照组与消融

  • 对照组:强模型上界、人工标注、随机基线。
  • 消融:提示模板(裸问 vs 让模型先定位再判断 vs CoT)、输入分辨率、temperature / beam。
  • 横向对比:不同 VLM + 不同提示策略,报精确率-召回率权衡曲线(不是单点)。

5. 高频坑

  • 负样本生成偏差:只换高频对象,模型凭先验"见过"就能猜,难度失真 → 掺入罕见对象/组合。
  • 拒答混入:把"不回答"单独记,否则会误判为"没幻觉"。
  • 若用 LLM 复核图像内容当 judge,同样要校准其自身的幻觉。
面试官追问
Q:POPE 的 yes/no 太简单,能代表真实幻觉吗?
它是"可自动、可复现"的下界测试,适合做回归门禁和横向对比,但不等于真实自由生成里的幻觉率。真实场景要补开放生成评估(如 CHAIR 式 caption 幻觉率、或用图-文一致性打分),两者配合用。
Q:模型"拒答"你怎么算?
拒答不算"判对"也不算"幻觉",单独记一个拒答率指标。如果模型靠大量拒答把假阳性率压到 0,要同时看它牺牲了多少召回——那是"躺平"不是"靠谱"。
Q:负样本怎么造才没有偏差?
别只随机换一个对象,要按"对象类别、出现频率、遮挡/小目标、罕见组合"分层采样负样本;并且负样本的"替换对象"要和原图语义可区分(换明显的、不相关的),避免模棱两可的样本污染。
Q:怎么证明是"看图幻觉"而不是"模型常识错"?
做"有图/无图"消融:同一断言在给图和不给图(纯文本)两种条件下测,幻觉率差就是图像引入的增量;也可以构造"图像与常识相反"的样本,看模型信图还是信常识。
术语卡
VLM:视觉语言模型,同时理解图像和文本。
对象幻觉:描述图像中不存在的物体。
反事实样本:人为改成"假"的样本,用于测幻觉。
假阳性率:负样本被判"有"的比例,幻觉核心指标。
POPE:Polling-based Object Probing,对象存在探测基准。
精确率/召回率:查准/查全,幻觉要重点看精确率。
