设计 VLM 幻觉问题的评估实验

⭐⭐⭐⭐ #VLM#幻觉#实验设计
先说人话:大模型看图会一本正经地编瞎话——图里只有猫,它偏说「旁边还有条狗」。这题要你设计一套实验,把编瞎话的频率测成可信的数字。面试官爱考它,因为答「找几个人看看输出对不对」直接暴露没做过评估;能把数据集、指标、对照组讲成闭环的,才真懂实验设计。
30秒电梯稿

"VLM 幻觉评估我按『五类幻觉 + 探测式数据集 + 双指标』搭:① 幻觉类型分对象存在、属性、关系、计数、OCR 文本五类,只做答案可判定的题型;② 数据集用 POPE 式『图像 + 一句断言,只许答 yes/no』:正样本取自图像标注里真实成立的事实,负样本来自对真图做『换对象/改属性/改数量』的反事实扰动,正负 1:1 配平、按对象频率分层,每题答案在出题时已知,可自动判分;③ 指标报 yes-准确率、精确率/召回率/F1,并单独盯『不该答 yes 却答了』的假阳性率(幻觉核心)和拒答率;④ 对照组:随机基线、无脑全 yes 基线、强模型/人工盲评上界;⑤ 消融:提示(裸问 vs 先定位再判断 vs CoT)、分辨率、解码温度,一次只动一个变量横向对比不同模型,报权衡曲线不报单点。"

通俗类比

VLM 幻觉是什么:视觉语言模型就是「大模型长了眼睛」,看图、说话两样都会;幻觉指它看图说话时一本正经地编造——图里只有一只猫,它描述完还补一句「旁边趴着条狗」。用你熟悉的话说,这就是备份系统里的「假成功报告」:作业实际没写成,报表却亮绿灯。哪里像:两者都是「输出比真相更自信」的静默错误,危害不在发生,而在不被发现——用户会拿着错误结果继续干活。哪里不像:假成功是确定性 bug,查到根因就能修;幻觉是概率模型的固有属性,像硬盘上的随机比特翻转,只能压低发生率、没法清零。所以评估的目标不是「证明它不幻觉」,而是「量化幻觉率、守住上线门禁」。

整套实验像容灾演练体系:不能等线上用户投诉「它瞎说」才发现问题,要平时主动写剧本、可复现打分。三个映射:① POPE 式「给一张图 + 一句断言,答 yes/no」像巡检探针——不问「集群感觉健康吗」,只发「活/死」二值的探测,答案机器可判、周周能跑;② 造负样本像故障注入:拿权威「资产台账」(图像标注)人为制造一个确定是假的场景,考系统能不能识别出「这是假的」;③ 正负 1:1 配平,像演练里正常流程和故障流程各占一半——不配平,一个只会报「正常」的笨系统也能拿高分。哪里像:都是「已知答案的剧本题」,胜在可复现、可当回归门禁。哪里不像:容灾演练考「故障下活下来」,这里考的恰恰相反——我们注入的不是故障而是「假象」,看模型会不会被带节奏跟着说瞎话。

指标就是告警系统那套精确率/召回率:模型答「图里有狗」= 发一条告警。精确率低 = 告警风暴,老爱瞎报「有」;召回率低 = 漏告警,真有狗它说没有;假阳性率 = 误报告警率,把「没有」说成「有」,正是幻觉的核心。哪里像:都在「少误报」和「少漏报」之间做权衡,报单点分数都会骗人,要报权衡曲线。哪里不像:告警阈值是你亲手配的,VLM 的「门槛」埋在模型权重里,你只能靠换提示、换分辨率去间接拧它——这也是为什么消融实验是这题的必答项。

详细拆解

一份合格的答案要长成「实验设计文档」:测什么 → 用什么题测 → 怎么打分 → 和谁比 → 哪里容易翻车。五步走完,面试官手里就有了一份能直接落地的方案。

第 1 步:先定「可判定」的幻觉类型(评估的前提是每道题都有标准答案)

第一刀先把「测什么」砍到只剩机器能判对的题型——这和容灾演练只验收可量化的 RTO/RPO、不验收「恢复感觉不错」是同一条工程纪律:不可复现的指标,写进门禁也没法兑现。

幻觉类型错的姿势举例(图里实际:一只白猫趴在木桌上)
对象存在说出图里没有的东西「桌子底下还趴着一条狗」(没有狗)
属性颜色/材质/大小/状态说错「一只黑猫」「大理石桌面」
关系空间或动作关系错「猫在桌子下面」「猫在追飞盘」
计数数量数错「图里有两只猫」(只有一只)
OCR 文本读错图里的文字图中指示牌写着「入口」,读成「出口」

「描述得生动不生动」这类主观题不进自动评估——不是不重要,而是不可复现:同一模型跑两遍分都不一样,分数就失去意义。

第 2 步:数据集构建(四步,灵魂是「答案在出题时就知道」)

带标注图像库(MSCOCO / GQA / 文档截图)
   │   图像标注 = 每张图的「资产台账」:有哪些对象、什么属性、什么关系
   │
   ├─→ 正样本:台账里真实成立的断言
   │        「图里有一只猫」(真,答案 yes)                  ┐
   │                                                    ├─ 正负 1:1 配平
   └─→ 负样本:反事实扰动,人为把真的改成假的              │  + 按频率/大小/遮挡分层
            「图里有一条狗」(换掉对象)                   │  + 人工抽验复核
            「猫是黑色的」  (改属性)                     ┘
            「图里有两只猫」(改数量)
   │
   └─→ 出成探测题:「图里有一条狗吗?」→ 模型只许答 yes/no → 对照混淆矩阵自动判分
  • 选图:用 MSCOCO / GQA 这类自带标注的公开库。为什么不自己人肉找图:标注就是每张图的权威「资产台账」,出题直接查台账,负样本也造得有据可查;文档截图类图像用来补 OCR 场景。
  • 造断言:正样本从台账直接读;负样本必须「确定是假」——反事实扰动:随机替换对象、改属性、改关系、改数量。POPE 论文把负样本按难度分了三档,这是造题的关键技术点:random 档从常用对象词表随机抽一个问「在不在」,最简单;popular 档专挑与图内对象高频共现的——图里有餐桌就问「有椅子吗」,模型最容易凭「餐桌配椅子」的语言先验上钩;adversarial 档挑与图中最相似对象共现频率最高的,最难,专测「完全没看图、全靠背」的模型。三档分工:random 测「真看错了」,popular/adversarial 测「被先验带节奏」——后者才是幻觉的主力成因,也是面试官眼里「懂行」的细节。
  • 配平与分层:正负 1:1。为什么必须配平:假如 90% 断言都是真的,一个无脑答 yes 的模型能拿 90 分,指标直接作废——和监控样本 99% 是正常、笨监控全答「正常」也有 99% 准确率是同一回事。分层:按对象类别、罕见对象、小目标/遮挡分层出题,防止模型靠「高频对象总在场」的先验白拿分——故障注入只测「磁盘满」一种,系统对断网断电照样没底,一个道理。
  • 人工复核:抽验负样本确实为假、正样本确实为真,控制标注噪声——像定期抽检备份数据是否真的可恢复:台账本身有错,后面所有分数都是沙上建塔。

第 3 步:指标(一张混淆矩阵看懂全部)

                      模型答 yes        模型答 no
断言为真(正样本)    TP 判对           FN 漏报(说「没有」→ 偏保守)
断言为假(负样本)    FP 幻觉!★        TN 判对

精确率   = TP/(TP+FP)  →「我说的有」里多少是真的;低 = 爱瞎说有(≈告警风暴)
召回率   = TP/(TP+FN)  →「真有的东西」抓到了多少;低 = 漏报(≈漏告警)
假阳性率 = FP/(FP+TN)  → 把「没有」说成「有」的比例;幻觉核心指标
F1       = 精确率与召回率的调和平均,一个数看综合
指标含义说明
yes-准确率正负整体判对比例粗看够,细看不够
精确率 / 召回率 / F1答 yes 里有多少真 yes;真 yes 里答对多少精确率低=爱瞎说有
假阳性率(幻觉率)负样本被答 yes 的比例幻觉核心指标,越低越好
拒答率模型"不答/说看不清"的比例单独统计,别和"答错"混

读表顺序:先看 yes-准确率定位整体水位,再看精确率/假阳性率定位幻觉,最后看拒答率查有没有「躺平刷分」——一个拒答 50% 的模型可以把准确率刷得很漂亮。报告里还要带上样本量:300 题上的 85% 和 3000 题上的 85%,可信度不是一回事。

第 4 步:对照组与消融(没有对照的数字都是孤证)

  • 随机基线 + 无脑全 yes 基线:1:1 配平后两者准确率都贴着 50%——但注意,全 yes 的召回率是 100%、假阳性率也是 100%,这正是「必须报多指标」的活教材;模型分数贴着 50%,立刻警觉。
  • 强模型 + 人工盲评当上界:人工标注结果当金标,定位误差天花板,看被测模型排在天花板和地面之间的哪里。
  • 消融:单变量纪律——一次只动一个旋钮,和调优分布式参数是同一门手艺:提示模板(裸问 vs 让模型先定位再判断 vs CoT)、输入分辨率、temperature / beam。
  • 横向对比:不同 VLM × 不同提示策略,报「精确率-召回率」权衡曲线而非单点——和压测报「延迟-吞吐」曲线同理:单点可以靠牺牲一头刷出来,曲线骗不了人。

第 5 步:高频坑(面试官最想听的就是这几条)

  • 负样本生成偏差:只换高频对象,模型凭先验「见过」就能猜对,难度失真 → 用 POPE 三档,再掺罕见对象/罕见组合。类比:只注入一种最简单的故障,演练成绩虚高。
  • 拒答混入:把「不答/看不清」悄悄剔除或算成答对,幻觉率会假性偏低 → 拒答单独记一栏。类比:把 skip 的备份作业从成功率报表里剔掉,报表干净了、保护能力一点没变。
  • LLM 裁判自身要校准:若用 LLM 复核图像内容当 judge(参见 LLM-as-a-judge),它自己也会幻觉——先在人工标注的小集合上量出它的错误率,超阈值就人工接管。
  • 数据泄漏(补一条):评估图若来自训练集,模型可能背过标注而不是在看图 → 用 held-out 图,或事后核对其是否出现在训练数据里。
面试官追问
Q:POPE 的 yes/no 太简单,能代表真实幻觉吗?
人话:它是「可自动、可复现」的下界测试——考卷简单,但能天天跑、能当回归门禁;它不等于模型自由描述时的真实幻觉率,别拿它对外宣传「我们幻觉率为 x%」。类比:像容灾演练里的单点故障注入:比真实灾难简单得多,但胜在剧本固定、每周能跑、结果可比;火灾级的大考要靠年度全量演练补。技术:上线门禁用 POPE 式探测;同时补开放生成评估——CHAIR 式 caption 幻觉率(数模型描述里提到但图中没有的对象占比)或图-文一致性打分,两者配合:一个管回归门禁,一个管真实感。
Q:模型"拒答"你怎么算?
人话:拒答不算对也不算错,单独记一栏;更要防的是靠拒答把幻觉率刷成 0 的「躺平模型」。类比:像备份作业 skip:不算成功也不算失败,混进任何一边报表都会失真;一个天天 skip 的备份系统报表干净,但什么都没保护。技术:单独报拒答率;幻觉率在「拒答不计分」和「拒答计错」两种口径下都报;若模型拒答 40% 换来假阳性率 0,同时看召回率掉了多少——躺平换来的低幻觉,必须在报告里点名。
Q:负样本怎么造才没有偏差?
人话:按维度分层、按难度分档,别让模型靠「见得多」白拿分。类比:故障注入只测「磁盘满」,系统对断网断电照样没底;注入要覆盖故障谱系,难度从「单盘故障」一路排到「双副本同时挂」。技术:用 POPE 三档:random(随机换对象)、popular(专挑和图内对象高频共现的,图有餐桌就问椅子,最考验抗先验)、adversarial(与图中最相似对象共最高的);再按小目标/遮挡/罕见组合分层;替换对象要与原图语义明显可区分,模棱两可的样本一律剔除,人工抽验兜底。
Q:怎么证明是"看图幻觉"而不是"模型常识错"?
人话:做有图/无图对照实验,两者的差值就是「图像带来的幻觉增量」。类比:像排查「告警是真故障还是监控误报」——把告警源摘掉再看现象是否还在,消融就是摘变量。技术:同一断言测两种条件:给图(走视觉通路)vs 纯文本(只考察先验);再造「图像与常识相反」的样本(一只猫泡在海水里),看模型信图还是信先验——信先验就说明视觉信号没真正用上;有图/无图幻觉率的差,就是图像引入的净增量。
Q:模型不听话,答"可能有一只狗吧",怎么判分?
人话:先把输出格式钉死,再给解析兜底,解析不了的单独记账,绝不悄悄丢弃。类比:老系统日志格式不规范,监控采集得靠「正则为主、关键字兜底、认不出的归 unknown」——默默丢日志,报表就虚高。技术:prompt 明确「只输出 yes 或 no」并给 few-shot 示例;解析走规则(首词/关键词匹配),失败再转 LLM 裁判判读;单独统计「格式违规率」,它不进幻觉率但必须出现在报告里;解码温度设 0,减少输出漂移。
术语卡
VLM:视觉语言模型,「大模型长了眼睛」,同时理解图像和文本,LLaVA 是典型代表。
对象幻觉:描述图像中不存在的物体——五类幻觉里最常被测的一类,POPE 主攻它。
反事实样本:人为把真事改成「假」的样本,答案已知,专门用来测幻觉。
假阳性率:负样本被判「有」的比例,幻觉核心指标,越低越好。
POPE:Polling-based Object Probing,对象存在探测基准——把「看图说话」拆成一道道 yes/no 判断题。
精确率/召回率:查准/查全;幻觉评估重点看精确率,它低就说明爱瞎说有。
混淆矩阵:TP/FN/FP/TN 四格表,一切二分类指标都从它算出来。
