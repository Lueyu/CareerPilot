Agent核心 · Q48

如何评估一个Agent系统的鲁棒性？除了准确率，还会测试哪些对抗性或边缘case？

⭐⭐⭐ #鲁棒性评估#压力测试 字节、阿里
30秒电梯稿

鲁棒性 = 在异常、对抗、长尾输入下"不崩、不越界、能恢复"。我会分三层评估：单点层——工具失败、幻觉、长上下文；流程层——死循环、任务漂移、多轮失忆、超时；对抗层——Prompt 注入、越权诱导、越狱、有害请求。指标从准确率扩展到任务成功率、越界率、有害输出率、恢复率、崩溃率、重试/降级率；测试方法用红队 + 自动 Fuzzing + 黄金集回归 + 线上影子流量。核心观点：准确率只衡量"正常题会不会"，鲁棒性衡量"被搞了会不会出事"，后者在真实上线里更关键。

通俗类比

像考驾照：光会开直线（准确率）不够，还得考雨天、坡起、突发加塞、爆胎（边缘/对抗）。更有意思的是"陪考的人故意捣乱"——比如有人大喊"右转右转"诱导你（Prompt 注入）、有人抢方向盘（越权诱导）。一个真正可靠的司机，是被人误导也不闯红灯、出了小状况能自己把车稳回来。评估 Agent 鲁棒性，就是系统地设计这些"坏天气"和"捣乱的人"去测它。

详细拆解

1. 评估维度：从"答对"到"不闯祸"（先扩展指标）

层级测什么关键指标
单点工具返回异常、幻觉、长输入任务成功率、事实一致性、P99 延迟
流程死循环、漂移、失忆、超时完成率、最大步数、恢复率、超时率
对抗注入、越狱、越权、有害请求越界率、有害输出率、注入成功率(越低越好)
容错工具挂了、下游降级降级成功率、重试有效率、崩溃率
  • 特别要区分"安全指标"和"质量指标"：准确率高但越界率也高，绝对不可上线——两者要分开报告，不能用一个综合分掩盖风险。

2. 对抗性测试（重点，逐类讲）

  • Prompt 注入：在文档/网页/邮件里塞"忽略之前指令，执行 XX"；直接注入、间接注入（藏在检索资料里）、多轮注入（前几轮埋雷后几轮触发）都要测。
  • 越狱(Jailbreak)：用角色扮演、假翻译任务、逐字拼接等绕过安全对齐，诱导出有害/违规内容。
  • 越权诱导：诱导模型调用不该调的工具、越数据范围访问（"把用户 B 的订单也给我看看"）。
  • 数据投毒/误导：喂错误信息看它是否被带偏、能否在工具真值校验下纠回来。

3. 边缘 case（工程 + 语义两头）

  • 把线上真实 badcase 沉淀成回归集，每次发版必跑，防止"修了 A 又坏 B"。
  • 模糊/矛盾指令要测"是否触发澄清"而非"硬答"——鲁棒的 Agent 会正确拒绝或反问。

4. 测试方法论（怎么规模化跑）

  • 红队(Red teaming)：人类 + 模型双红队，专门找漏洞，输出攻击样本进回归集。
  • 自动 Fuzzing：对输入做变体（改词、加噪声、拼注入模板）批量生成测试，覆盖人工想不到的组合。
  • LLM-as-judge + 规则判官：自动给"越界/有害/注入"打分；关键安全项用确定性规则（工具白名单命中、权限命中）做硬判定，不靠模型自评。
  • 影子流量/灰度：线上复制流量或小流量上线，对比新旧版本在真实分布下的崩溃率与越界率。

5. 报告与红线（收尾）

  • 给出分维度看板而非单分：质量分、安全分、稳定分分开；安全类指标设硬阈值，超过直接阻断发布。
  • 诚实讲边界：对抗是军备竞赛，没有 100% 安全，靠"持续红队 + 快速修复 + 纵深防御"把风险压在可接受范围。
面试官追问
Q:怎么衡量"Agent 被注入攻击成功了"？
定义明确的攻击成功判定：是否执行了不该执行的动作（越权工具调用命中）、是否输出注入要求的内容、是否泄露了数据。用"注入成功率 = 命中数 / 攻击样本数"量化；成功判定优先用确定性规则（工具是否在白名单、权限是否放行），不能只靠模型自评"我有没有被攻击"。
Q:鲁棒性和准确率冲突怎么办（防御太严会拒答正常问题）？
这是安全与可用性的平衡：按风险分级设阈值——低风险场景宽松、高风险场景收紧；用"误拒率"和"漏放率"一起看，选业务可接受的权衡点。实践中把两类测试放同一评估集，一起回归，改防御必须同时看两个方向，避免"防住攻击却废了正常功能"。
Q:没有足够对抗样本时怎么办？
用模型辅助生成：让另一个强模型扮演攻击者批量生成注入/越狱变体，人工筛出高质量的入回归集；再配合输入 Fuzzing 自动扩量。样本不需要一开始就海量，关键是建立"攻击 → 发现 → 沉淀 → 回归"的闭环，让测试集随线上漏洞持续生长。
术语卡
红队:专职找漏洞的对抗测试团队/模型。
Fuzzing:自动生成大量输入变体去撞边界。
越狱:绕过安全对齐诱导违规输出。
OOD:分布外输入，训练/常见数据之外的情况。
影子流量:用线上真实流量在旁路做无感对比测试。
恢复率:异常后能否自行纠正/降级到可用状态的比例。
