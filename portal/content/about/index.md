## 这是什么网站

agent-interview.icu 是一个**公开的知识门户**：面向 AI Agent 方向的工程师，提供学习路线、技术指南、公开面试题和实践实验室（Hands-on Labs）。所有内容免费阅读，遵循 CC BY-NC-SA 协议。

本站是**纯静态网站**：没有账号系统、没有用户数据库、不收集任何个人信息。

## 和 CareerPilot 的关系

[CareerPilot](/about/) 是一个运行在**你自己电脑上**的私人职业进阶工作台：导入面经、能力诊断、学习计划、项目资产——你的所有数据（答卷、画像、记忆）只存在本地，绝不上传。

本门户与 CareerPilot 职责不同：

| | agent-interview.icu（本站） | CareerPilot |
|---|---|---|
| 定位 | 公开知识门户 | 私人工作台 |
| 数据 | 全部公开内容 | 全部本地私有 |
| 账号 | 无 | 本地单用户 |

CareerPilot 中审核通过的**公开内容**（学习路线、指南、公开题）可以发布到本站；本站的内容也可以拉回 CareerPilot 作为学习资料——数据流单向受控，隐私红线（见下）永不越界。

## 内容从哪来

- **原创**：由 CareerPilot 维护者撰写，标注 `source_type: original`。
- **社区贡献**：通过 GitHub Pull Request 提交，审核合入。
- **CareerPilot 发布**：用户在本地工作台创作并主动发布的内容，发布前经过隐私扫描（绝不包含个人答卷、画像、私有记忆）。

## 隐私红线

无论何时，以下内容**永远不会**出现在本站：

- 用户的私有面经、答卷、评分记录
- 用户的能力画像、学习记录、记忆数据
- 任何含个人信息的原始截图或文档

## 联系与参与

- 内容勘误或投稿：在 GitHub 仓库提交 Issue / Pull Request
- 发现隐私泄露嫌疑：请立即通过 GitHub Issue 报告，我们会第一时间下线核查
