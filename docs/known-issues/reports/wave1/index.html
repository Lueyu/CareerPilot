施工时间线

第 1 波 · 止血

逐项理解并发、预算、认证、输入安全与运维保障。每篇从事故场景讲到原理、修改、验证和边界。

E1 · 验证通过，独立审核 PASS+NOTES

聊天生成增加工作区准入和进程内执行上限

让跨会话聊天需求先经过有上限的准入判断，避免一个工作区通过大量会话同时启动模型。容量已满时及时返回可重试的拒绝，不留下未被接受的消息，也不破坏原来的流式回复、幂等提交、中断、重试和恢复行为。

E2 · 实现与验证记录

私有模型按配置单价预留与结算，部署日预算在联网前生效

让聊天、评分和后台生成共用可追溯的货币预算。每次真实模型请求先留下资金记录，再允许联网；供应商没有可靠用量时明确标为未知，防止备用调用、取消或业务回滚造成漏账。

E3 · 实现与验证记录

API 在业务执行前按可信工作空间限流，并实施严格日请求额度

让 CareerPilot 的主要 API 在写入数据、创建后台任务或调用付费模型之前，先检查请求速度和当天请求次数。合法的读取、普通写入和可能生成模型内容的操作分别管理；拒绝时给调用方明确的等待时间，同时保护个人数据和原有评分证据。

G5 · 实现与验证记录

让后台模型密钥与仓库令牌以绑定上下文的密文落库

完成 Wave1 G5，让全局及工作区的后台 LLM、GitHub、GitCode 凭据不再以明文存入数据库，并让缺钥、损坏或被搬运的密文在联网前明确拒绝。交付还包含可重试的显式迁移和面向初学者的机制说明。

F6 · 实现与验证记录

加密备份、受控复制、保留与新库隔离恢复

把数据库副本变成可验证的标准 age 加密归档，用真实 PostgreSQL 演练证明原答与证据能恢复，并让恢复出的旧认证和旧预算默认不能继续运行。交付范围止于已验证、仍隔离的新备用库。新公开实例也会先准备恢复控制表，再由操作员显式登记可运行状态。

G6 · 实现与验证记录

个人版安全启动：首次随机凭据可稳定复用，网页不再内置令牌

让个人版在任何数据库写入、恢复任务和后台联网之前拒绝明显弱凭据，同时保留可理解、可重复的首次安装路径。使用者升级后不会因为重启悄悄换令牌；复制网页产物也拿不到部署时的访问凭据。

H1 · 实现与验证记录

让访问凭据真正可以到期、撤销和轮换，并保护长期工作空间归属

完成第1波H1。在已有G6强凭据检查之后，为本地API提供可以实际操作的凭据生命周期。操作员通过离线命令明确登记或签发凭据，撤销和轮换不需要重启服务，其他进程也会立即读到提交后的变化。工作空间归属独立保存，凭据失效不能把租户数据交给本地owner。

H2 · 实现与验证记录

让模型URL校验约束真正的TCP连接

完成获批Wave1 H2。让保存、连接测试与实际模型请求共享出站安全策略，保护服务器内网和模型凭据，同时保留原有端点定价与密文归属。

H8 · 实现与验证记录

给五处嵌套输入建立边界，并保持题库全集分页完整

完成批准的 Wave1 H8：非法字段、错误类型、过大或过深 JSON 在业务处理前安全拒绝；合法作答、审批、遥测与发布规则保持兼容；题库降低单页上限后，资料库仍取得完整库存。

H3 · 源码与实例已验证

导入面经始终作为资料，保留原文并提示可疑指令

让个人、注册 native 和仍可访问的 seed 面经导入在提取、补答案、改写及审核时保持资料身份。用户可在原有审核区对照完整保存的解析原文，看到确定性的来源和原因提示，再决定如何处理草稿。

H4 · 源码与实例已验证

让个人版与公开版共用受限文档解析

让网上下载的面经经过共享的资源检查，并在解析超时或取消时结束相关进程。保留个人版更多文件格式与公开版较小上传限制；错误文件仍有明确原因，同批合法文件可以继续形成待审资料。

A2 · 实现与验证记录

让题库问句找准主题，也走对处理流程

A2 的目标是让普通中文、英文和中英混合的列题请求保留真实主题，返回有来源、总数清楚的题库清单，同时保留用户要求的解释、比较或回答任务。本报告帮助初学者理解修复原因、代码机制和证据边界。
