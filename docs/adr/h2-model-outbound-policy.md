# H2 模型出站连接策略

状态为已实现，验收证据由本项运行目录提供，独立终审由父代理执行。

模型 URL 是不可信配置。设置页保存时检查 URL 和全部 DNS 答案；实际模型连接时重新检查，并把检查通过的字面 IP 交给 httpcore 的 AnyIO 网络后端。单纯保存时查一次 DNS 不能阻止 DNS rebinding。HTTPX 请求 URL、HTTP Host、连接池 origin 和 TLS 证书验证及 SNI 保留原域名。E2 价格匹配与账本 endpoint、G5 密文所属设置及字段均保持原有身份，不写成 IP。

`ModelOrigin` 表示协议、主机和有效端口，`ModelEndpoint` 保留逻辑 URL，`VettedDialTarget` 只表示 TCP 的目标。`PinnedModelTransport` 复用 HTTPX 流和异常适配，只替换 httpcore 连接池的 network backend。相比重写 URL 再手动补 Host/SNI，该方案保留成熟的 HTTP 和 TLS 行为。HTTPX 没有公开的 network_backend 构造参数，因此这里依赖 `_pool` 适配点和 httpcore 的 AnyIOBackend。依赖限制为 HTTPX 0.28.x、httpcore 1.0.9 至 1.0.x；升级时必须重跑连接、TLS 和流式行为测试。

默认只接受公网 HTTPS。拒绝用户信息、查询、片段、控制字符、歧义数字地址、不支持的协议、IPv4-mapped IPv6、私网、回环、链路本地、组播、保留和未指定地址。一个答案不安全就拒绝整个答案集。仅部署侧 `MODEL_LOCAL_ORIGINS` 可以精确允许 HTTP、私网或回环模型。例如 `MODEL_LOCAL_ORIGINS=["http://127.0.0.1:11434"]` 对应 `LLM_BASE_URL=http://127.0.0.1:11434/v1`。列表中不能包含路径；协议、主机、端口都参与匹配。有效默认端口等价，IPv6 展开与压缩形式等价。即使配置例外，也拒绝链路本地、组播、未指定、映射 IPv6 和其他保留地址；精确回环例外专门支持 `::1`。设置请求、存量 DB 配置和 `SEED_LOCAL_UNMETERED` 都不能扩大网络权限。

迁移时，普通公网 HTTPS 网关无需新增例外。原先隐式可用的回环 HTTP 模型现在需要精确部署授权。公开网关 compose 转发此 JSON；本机启动器转发操作员配置，使用个人模型时继承其部署侧列表。租户生成器只给 API/worker 声明生成的内部模型 relay origin，另向 sidecar 转发可信部署侧的上游 origin 列表。不要把子网、通配符或任意 localhost 当作列表。这里不修改个人环境，也不自动部署。

个人、工作区存量配置、连接测试、流式与非流式调用都进入同一适配器。注册网关的 `public_model`、租户 relay 和反馈模型审核也使用同一网络策略。代理环境变量与环境 CA 设置不参与模型客户端；客户端明确关闭自动重定向，收到 3xx 就失败，不向新 origin 转发凭据。私有调用先做无网络的语法及字面地址校验，再持久预留，最后 DNS/TCP；预算拒绝时零 DNS、零 TCP。注册调用也保持自身 `_claim` 在 DNS/TCP 之前。DNS 阶段拒绝或取消后，既有未知用量保留预留，不伪造零用量退款，不增加账本状态。

已知策略拒绝抛出固定错误码 `MODEL_OUTBOUND_POLICY` 和固定安全文案。学习自动备用、规则降级及题目改写路径不得吞成成功结果。公开教练将同一安全文案写入失败终态。供应商响应体、实际地址、DNS 错误、异常文本和密钥不进入该文案。一般供应商失败仍可按原规则备用，备用保留自身端点与凭据并独立预留。

DNS 每进程最多八个实际 OS 查询。调用方最多等三秒，连接超时时间更短时取更短值。线程完成才归还名额，调用取消或超时不会提前归还。迟到异常有消费者。操作系统查询本身不可强制取消，八个查询长期卡住会使该进程后续解析失败关闭，并可能延缓进程退出。64 个答案上限在 OS 返回后检查，不能宣称它限制 OS 解析时的内存。当前只拨第一个已通过校验的地址，不自动尝试其余地址，存在双栈可用性取舍。该策略不替代部署网络防火墙，也无法识别操作员特意配置的代理在远端继续转发的最终目的地。

验收使用合成配置、受控 DNS、底层字面 IP 观察和回环 HTTP/TLS 服务。真实 TLS 测试使用仅在测试里信任的临时证书，证明原主机名成功而错误主机名拒绝。响应 MockTransport 只证明解析、业务和账本行为，不能证明 TCP pinning。没有真实供应商兼容性或线上部署结论。继承的结算重复取消风险保持原状，不在 H2 扩大 E2/F8 重构。
