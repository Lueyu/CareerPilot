# CareerPilot 公开注册种子版设计

2026 年 11 月 23 日。目标是在阿里云向中国大陆求职者提供一个能自行注册、建立私有题库、练习面试并带着进度回来的版本。基于本地 `dev` 的 `af9b952` 设计。本文供开发前审阅。

## 用户第一次能做什么

用户在 `app.agent-interview.icu` 注册，只填目标岗位，先选练习方向。每个方向有一道示例题。用户可以修改岗位或补充招聘要求。原来保存的题和作答保留原来的岗位归属。方向和题目按用户、岗位保存，重新打开时读已有结果。

例如，产品运营用户选“用户增长”，后端开发用户选“接口与数据一致性”。两人都可以从以下入口开始。

| 入口 | 用户操作和结果 |
| --- | --- |
| 我的题库 | 打开一个方向，先看到自己已有的题。新方向可以生成起步题。每道题都能进入学习或面试。 |
| 导入面经 | 上传文本型 PDF、Word `.docx` 或 Markdown。预览候选题和原文答案，修改或勾选后保存到本人题库。界面标出 AI 补充的内容；提取不到文字时，提示换文字版文档。 |
| 学习助手 | 用户说“我想练三道活动复盘题”，可以继续说“第二题换成实习场景”，最后只收藏满意的题。聊天记录保留；同一候选题连续点两次只保存一份。 |
| 面试官 | 选中一道题后先独立回答，再接受针对回答的追问。结束后看到自己答到了什么、遗漏了什么、可以怎样改进。中途求助的回答标记为已获提示。已有评分或复测条件不足时，展示点评并保留能力状态为未知。 |
| 项目记忆 | 可手动填写，也可以把对话中本人提过的经历转成待确认条目。确认后才写入，能查看、更正和删除。项目可以是一次实习、运营活动、课程作业或工程工作。将用户陈述、材料中的事实和助手提出的练习建议分别记录。 |

例如，运营用户确认“我负责社群拉新”后，面试官可以追问她如何区分自然增长和活动贡献。她没提供转化率时，点评可以建议补充转化数据；记忆中只保存她确认过的事实。

所有自建题、上传材料、项目记忆、对话和作答默认私有。社区分享进入后续版本，由用户逐题选择公开内容。种子版用一道题上的“有问题”入口收集反馈，默认仅附本人选中的题和反馈文字。

## 注册、模型费用和资料归属

- **账号。** 首版建议“用户名＋密码＋一次性恢复码”。找工作的人可在手机浏览器注册，无须等待邮件或短信。注册时只展示一次恢复码，明确提示保存。恢复码只能用一次，重置密码后撤销已有会话并发新码。用户名重复时给出可操作的提示。密码和恢复码仅保存安全哈希，服务端会话使用安全 Cookie，对写操作校验请求来源。
- **空间。** 注册成功时在同一事务创建账号、工作空间和成员关系。账号只能访问其所属空间。题库查询、文件解析、候选题、聊天流、异步任务、导出与项目记忆都沿用该空间身份。外部部署使用新数据库和独立密钥，数据库只在内部网络提供服务。公网模式遇到默认开发凭据或缺失身份配置时停止启动。
- **费用。** 平台从服务端调用模型，每人每日额度和全站月度额度均可配置。首月模型上限沿用讨论中的 50 元方案，以运营者设置为准。按模型单价和输出上限预留后再调用，并发、重试和用量回写共用一次调用记录。供应商缺失用量时标记未知并保留预留。达到上限时说明恢复时间，已有题目、作答和笔记仍能打开。
- **隐私和恢复。** 上传前显示用途、实际存储地域、哪些内容会发送给哪家模型服务商，以及删除方式。原始文件仅为解析临时保存。用户能导出自己的资料、删除经历和账号。日志记录请求编号、错误、耗时和可核对的用量；反馈复现优先用合成材料。云端数据库每日加密备份到独立位置，发布前用测试账号演练一次恢复。

## 阿里云地域由大陆实际体验决定

首选阿里云上海，杭州可作为内地备选。内地节点对外提供网站前，核实域名对应网站的 ICP 备案及阿里云接入状态。域名能解析只能证明 DNS 工作。若内地接入暂不具备，先验收中国香港候选。只有新加坡在目标用户的大陆网络通过下列同等测试，才考虑启用；数据存储和第三方处理地域也要在用户上传前据实说明。[阿里云备案与接入](https://help.aliyun.com/zh/dns/pubz-filing-domain-name-related-faq) · [地域与公网带宽说明](https://help.aliyun.com/zh/simple-application-server/use-cases/build-an-e-commerce-platform/)

先评估 Linux 2 核 4 GB 单机，复用网页、API、PostgreSQL 及必要任务进程；用两人同时上传与聊天检查资源是否够用。核价时记录地域、线路、带宽、续费和备份成本，以阿里云购买页为准。上轮讨论的腾讯云价格不适用于阿里云。首选使用应用自己的静态资源，减少大陆用户访问外部字体、脚本或登录服务的依赖。[阿里云规格](https://help.aliyun.com/zh/simple-application-server/product-overview/instance-families/) · [计费项](https://help.aliyun.com/zh/simple-application-server/product-overview/billable-items)

11 月 23 日从本机绕过 HTTP 代理，向阿里云三个地域的 OSS 根地址各发五次独立 HTTPS HEAD 请求。五次均收到 HTTP 404，说明端点有应答。上海、香港、新加坡收到首字节的中位数分别为 0.099、1.826、2.411 秒。未验证本机出口运营商。这组样本只用于安排候选地域顺序。正式决定使用候选应用页面和真实模型响应的测量结果。[阿里云公布的地域端点](https://help.aliyun.com/zh/oss/user-guide/regions-and-endpoints)

**种子版拟采用的体验目标**如下。这些是发布目标，尚待应用实测。在大陆固定宽带和手机蜂窝网络各做五轮。地区间保持相同版本、模型、简短提示词和合成面经，按网络分别记录中位数、最慢值与失败次数。看模型首段时记录浏览器收字的时间，并记录服务端收到上游首段的时间，方便区分模型等待与网页转发。

| 场景 | 可观察目标 |
| --- | --- |
| 冷打开首页 | 从打开 URL 到注册或登录表单能操作，中位数不超过 3 秒。 |
| 导入面经 | 约 1 MB 的文本型 PDF 上传后能看到已接收或正在解析，并最终进入候选题预览。记录上传确认及预览分别用时，同一任务刷新后能找到。 |
| 学习助手 | 从点击发送到首段有意义的可见回答，中位数不超过 5 秒。占位符、心跳和“正在思考”分别记录。续传后的最终答复与存入会话的内容一致。 |
| 地域选择 | 两类网络都能完成注册、上传和对话。某个地域反复超时或超过首屏、首段目标时先排查上游和转发，再复测。缺少合格实测时，新加坡不作为首发地域。 |

## 怎样算今晚能交给用户

1. 在全新云端测试库，用两台浏览器自行注册“后端开发”和“产品运营”两个账号。两人看到各自岗位的方向。退出再登录能恢复选择。
2. 分别导入不同资料，三个支持格式各走通一次。确认前能编辑或跳过候选题，确认后能从本人的题库打开。重复提交同一审核结果保持题目数量一致。
3. 两人同时进行一轮真实模型对话，各自要求生成多道题、修改一题、只收下一题。进入模拟面试独立回答，接受一次基于原答的追问，结束后能找回原答和点评。
4. 运营账号添加并确认一段经历，下次面试能引用对应事实。用两个合成账号检查列表、详情、对话、导出和后台结果的归属。删除经历后重新开一轮面试，助手不再将该条作为项目记忆引入。
5. 验收注册后找回账号、失效会话、模型额度用尽、模型超时、导入失败和备份恢复。用测试数据核对公开资源中没有个人实例的资料。记录首次练习完成、导入失败和用户主动反馈，能区分模型费用与未知费用。
6. 在独立云实例和子域名上通过大陆网络验收，记录实际 URL、版本、地域、真实模型、网络样本及两个测试账号的结果。依赖未齐时可交付已验证的隔离版本，并明确公网还欠哪项。最终对外交付以可注册、可持久化的 HTTPS 网址和这两条用户路径为准。
