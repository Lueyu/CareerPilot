# CareerPilot 面试学习教练

本机入口为 [学习聊天](http://127.0.0.1:5173/study/chat) 和 [我的笔记 / 复习](http://127.0.0.1:5173/study/notes)。2026-11-18 的个人页面使用 `127.0.0.1:8002/api/v1`，数据存放在 PostgreSQL 的 `careerpilot` 库。刷新或重新打开页面后可以继续。

## 聊天、对照和复测

1. 从「学习聊天」提问。桌面默认显示专注阅读，手机点「会话」找回历史。
2. 在要保留的回复下点「整理这条回复」。生成完成后，「打开笔记」进入单栏编辑，「对照原聊」定位到对应会话与回复。笔记内可随时切换「专注笔记」和「对照会话」。宽屏左侧是原文，右侧可以编辑。窄屏从「跳到来源会话」查看原文。未保存的编辑暂存在当前浏览器和工作区。点「保存笔记」后才产生服务端版本。
3. 从已保存版本生成候选卡，然后进入「复习与练习」启用卡片。参考答案默认折叠。点「主动练习」提交首次原答，随后可以请求提示、看反馈、提交修正。练习记录分别保存每次作答与当时的帮助情况。
4. 点「生成新情境复测」，打开试题并独立作答。评分完成后可以查看本题得分、有效证据和画像快照，返回来源笔记或继续聊天。

## 使用

输入一个面试问题，或从题目、错题评价、学习计划进入。左侧可按时间查找、重命名、移除会话，手机上通过抽屉打开。Enter 发送，Shift+Enter 换行，中文输入法确认候选词时不会发送。草稿按工作区及会话保存在当前浏览器。语音转文字沿用浏览器能力。

想了解实现时，选中「关联项目」，输入具体模块、行为或符号，再点「结合我的项目」。回复的材料可展开查看文件、符号、行号、版本和当时读取的片段。本地未提交代码以文件字节的 SHA-256 为版本。已有分析可提供固定提交版本的源码记录。如果只有报告或检索没有命中，模型会收到明确的覆盖缺口。静态引用不能证明某段代码已经执行或由用户编写。

「画图讲解」和「交互演示」支持放大和查看结构化源码。演示包括分块、重试、检查点恢复和并发排队。滑块和开关改变模拟计算；控件设置只保存在当前浏览器。生成器提供数据和说明，实际交互代码由应用提供。正文支持表格、公式、代码高亮和复制。

「围绕这条追问」可指定旧消息。编辑和重新生成会追加版本，后续生成沿对应分支读取历史。要练面试表达，选「面试官追问」；要记录可评分的独立作答，进入「测一下」。只听讲也能点「整理成笔记」。如已选中某条回复，笔记和练习会保留聚焦消息。可在我的笔记中编辑、刷新、生成候选卡并启用。复习卡自评改变下次出现时间。练习、提示后修正与新情境复测分别留档。

## 启动与迁移

本机已有数据库、API、网页和常驻 worker。冷启动时先启动原有 PostgreSQL，确认所选 API 和网页端口空闲，然后在仓库根目录执行：

```powershell
.\deploy\backup.ps1
$env:PYTHONPATH = (Resolve-Path .\personal\runtime\local-start-platform).Path
.\deploy\start-personal.ps1 -Port 8002 -WebPort 5173
Invoke-RestMethod http://127.0.0.1:8002/healthz
```

第二行是这台 Windows 电脑既有的进程级 Python 平台信息兼容设置，其他机器通常只需前后两条启动与健康检查命令。启动器会初始化数据库、顺序执行幂等迁移，并启动或复用 worker。新检出需先安装 `server/requirements.txt` 与 `web` 的 npm 依赖。单独应用数据库迁移可在 `server` 目录执行 `.\.venv\Scripts\python.exe migrate.py`。

迁移 `013_study_coach.sql` 增加消息的 JSONB 元数据和会话移除时间，历史消息的默认元数据为 `{}`。退回之前的应用版本时先停止使用新字段的服务，使用 `docs/study-coach-rollback.sql` 将新元数据归档到 `coach_013_archive` 并回退列。重新应用 013 后可按同一消息或会话 ID 回填归档列。本次已在从个人备份恢复出的隔离库演练。

## 应用模型与执行

- FLASH 继承现有设置页中的服务商、密钥、网关、模型。可以用服务端 `STUDY_FLASH_MODEL` 覆盖模型。当前请求模型为 `deepseek-v4-flash`。
- STRONG 由服务端 `STUDY_STRONG_MODEL` 指定，本机为同网关的 `deepseek-v4-pro`。不同网关需同时配置 `STUDY_STRONG_BASE_URL`、`STUDY_STRONG_API_KEY` 及相应 provider。密钥只存在后端。
- Auto 综合教学动作、问题涉及的机制、上一轮已用档位、短追问语义、文件数、版本冲突及已声明的能力。简单澄清优先快速档；深入机制、跨文件项目分析、复杂产物使用深度档。可手选 Flash/Strong。需要独立证据的开放式学习复测通过统一评分 worker 请求强档。
- `STUDY_FLASH_CAPABILITIES`、`STUDY_STRONG_CAPABILITIES` 是部署声明的能力清单。此版通过文本流和本地只读工具实现教学，未向模型开放任意工具或视觉输入。容量设置是本应用的输入限额，不代表厂商公布的最大上下文。优先压缩久远的背景，保留来源消息 ID。
- 默认一轮最多 120 秒、输出预留 6,000 tokens，Auto 至多两次模型请求。允许合适的快速档失败转深度档，以及深度档对无效图形的一次有界修复。手选模型保持固定。能力、预算或服务不足会显示可恢复失败。每次调用区分请求模型与网关报告名，保存耗时、用量、错误及代次。未配置可信单价时费用显示未知。墙钟与输出限额可通过 `STUDY_TIMEOUT_SECONDS`、`STUDY_OUTPUT_BUDGET` 调整。
- 用户消息和排队状态先提交，前端同步服务端保存的分段结果。切换会话不改变运行归属，刷新后读取最新快照。停止、超时和重试通过消息 ID、尝试编号、租约及数据库条件更新防止迟到回复覆盖现状。服务意外退出后，过期任务进入可重试状态。
- 绑定本地代码时，`STUDY_PROJECT_ROOTS` 使用 JSON，将 `工作区ID:项目ID` 映射到管理员批准的绝对目录。本机绑定为 `5:7` 对应 CareerPilot。服务端先做所有权检查，再筛选安全路径，排除个人数据、凭据、链接和超限文件。未绑定目录的项目可使用同工作区已有分析中具有版本与内容校验值的代码。当前方法支持有界静态检索；间接或动态调用可能漏检。
- 正文渲染沿用 React，新增 Markdown、GFM、公式和高亮依赖以展示原始内容。产物只接收经校验的声明式数据，模型给出的脚本、HTML 与远程资源不会作为学习网页执行。真实图表要求数值与所引数据字段一致。

主要入口为 `server/app/api/v1/study_chat.py`、`server/app/services/study_chat.py`、`study_routing.py`、`study_project_evidence.py`、`study_blocks.py` 和 `study_teaching.py`。复用原有 study_notes、study_practice、assessment_jobs 和 assessment_worker。界面位于 `web/src/pages/StudyChat.tsx` 和 `web/src/components/Study*.tsx`。教学来源、版本与许可证见 [原学习助手说明](study-assistant.md)。本次没有修改 pstack 的角色模型分配。
